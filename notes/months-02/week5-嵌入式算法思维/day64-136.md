## #26 删除有序数组重复项

**【题目描述】**
给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**【关键词】**
异或

**【核心技巧】**
- 一个数和 0 做 XOR 运算等于本身：a⊕0 = a
- 一个数和其本身做 XOR 运算等于 0：a⊕a = 0
- XOR 运算满足交换律和结合律：a⊕b⊕a = (a⊕a)⊕b = 0⊕b = b

故而在以上的基础条件上，将所有数字按照顺序做异或运算，最后剩下的结果即为唯一的数字

**【复杂度分析】**

**一、时间复杂度**

详细分析：

1. 循环次数：
 - 循环从 i = 0 到 i = numsSize - 1
 - 总共执行 numsSize 次循环
 - 设数组长度为 n，则循环执行 n 次

2. 每次循环的操作：
 - 一次异或运算，时间复杂度 O(1)
  

3. 总时间复杂度： n × O(1) = O(n)
- 最好情况：n=1，执行 1 次循环
- 最坏情况：n 很大，执行 n 次循环
- 平均情况：执行 n 次循环


**二、空间复杂度是 O(1)：**
- 固定数量的变量：2个（ans 和 i）
- 空间使用与输入规模 n 无关
- 空间复杂度 = O(1)
