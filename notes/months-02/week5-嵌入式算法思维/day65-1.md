## #1 两数之和

**【题目描述】**
给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target  的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

**【关键词】**
哈希映射，空间换时间

**【核心技巧】**
- 由于哈希查找的时间复杂度为 O(1)，所以可以利用哈希容器 map 降低时间复杂度
- 遍历数组 nums，i 为当前下标，每个值都判断map中是否存在 target-nums[i] 的 key 值
- 如果存在则找到了两个值，如果不存在则将当前的 (nums[i],i) 存入 map 中，继续遍历直到找到为止
- 如果最终都没有结果则抛出异常

**【复杂度分析】**

**一、时间复杂度**

详细分析：

1. 循环次数：
 - 循环从 i = 0 到 i = numsSize - 1
 - 总共执行 numsSize 次循环
 - 设数组长度为 n，则循环执行 n 次

2. 每次循环的操作：

```text
struct hashTable* it = find(target - nums[i]);   // 哈希查找 O(1)
if (it != NULL) {                               // 判断 O(1)
    // 分配内存和赋值 O(1)
}
insert(nums[i], i);                             // 哈希插入 O(1)
```

1. 总时间复杂度： n × O(1) = O(n)
- 最好情况：n=1，执行 1 次循环 (前两个数就符合条件)
- 最坏情况：n 很大，执行 n 次循环 (循环到最后或未找到)
- 平均情况：执行 n/2 次循环  (在中间某位置找到)


**二、空间复杂度是 O(1)：**
1. 额外使用的空间
 - 代码中的变量
  ``` C
     hashtable = NULL;                    // 哈希表指针：O(1)
     struct hashTable* it;                // 临时指针：O(1)
     int* ret = malloc(sizeof(int) * 2);  // 返回数组：O(1)固定大小
  ```

  - 主要空间消耗： 哈希表
  ```C
  // 每次插入可能分配：
  struct hashTable* tmp = malloc(sizeof(struct hashTable));
  ```
 - 每个节点包含：
    - int key：4字节
    - int val：4字节
    - UT_hash_handle hh：uthash 内部结构（约24-32字节）
 - 每个节点约32-40字节

2. 空间复杂度计算
 - 最坏情况分析：
  - 如果遍历完整个数组都没找到解，需要将所有 n 个元素插入哈希表
  - 哈希表存储 n 个节点
  - 空间消耗与 n 成正比
 - 空间复杂度：O(n)，其中 n 是数组长度
