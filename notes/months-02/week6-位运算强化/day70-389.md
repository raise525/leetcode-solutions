## #389 找不同

**【题目描述】**
给定两个字符串 s 和 t，它们只包含小写字母。字符串 t 由字符串 s 随机重排，然后在随机位置添加一个字母。请找出在 t 中被添加的字母。

**【关键词】**
位运算 | 哈希表 | 计数

---

**【核心技巧】**

#### 一、位运算 —— 异或消消乐

**核心思想：** 异或运算的性质
- 相同数字异或为 0：`a ^ a = 0`
- 任何数字与 0 异或不变：`a ^ 0 = a`
- 异或满足交换律和结合律

**解题思路：**
1. 将 s 和 t 中的所有字符进行异或运算
2. 相同的字符会两两抵消为 0
3. 最后剩下的就是被添加的那个字符

**为什么可行？**
- s 中的每个字符出现一次
- t 中的每个字符也出现一次，但多了一个字符
- 所有字符异或后，成对的字符抵消，多出的字符保留


#### 二、计数法（哈希表/数组）

**核心思想：**
1. 统计 s 中每个字符出现的次数
2. 遍历 t，对应字符计数减 1
3. 当某个字符计数变为负数时，说明它是多出来的字符

**代码实现：**
```
char findTheDifference(string s, string t) {
    int count[26] = {0};  // 26个小写字母
    
    // 统计 s 中字符出现次数
    for (char c : s) {
        count[c - 'a']++;
    }
    
    // 遍历 t，减少计数
    for (char c : t) {
        count[c - 'a']--;
        // 如果计数变为负数，说明这个字符在 s 中不存在或数量不够
        if (count[c - 'a'] < 0) {
            return c;
        }
    }
    
    return ' ';
}
```

#### 三、求和相减法

**核心思想：**
1. 计算 t 中所有字符的 ASCII 码之和
2. 减去 s 中所有字符的 ASCII 码之和
3. 差值就是添加字符的 ASCII 码

**代码实现：**
```
char findTheDifference(string s, string t) {
    int sum = 0;
    
    // 累加 t 的字符
    for (char c : t) {
        sum += c;
    }
    
    // 减去 s 的字符
    for (char c : s) {
        sum -= c;
    }
    
    return (char)sum;
}
```

**【复杂度分析】**

**一、时间复杂度**

详细分析：

1. 三种方法分析：
   - 位运算法：遍历 s 和 t 各一次 → **O(n + m) = O(n)**
   - 计数法：遍历 s 和 t 各一次 → **O(n + m) = O(n)**
   - 求和法：遍历 s 和 t 各一次 → **O(n + m) = O(n)**

2. 关键点：
   - 无论哪种方法，都需要完整遍历两个字符串
   - n 为 s 的长度，m = n + 1 为 t 的长度
   - 总操作次数 ≈ 2n + 1

3. 总时间复杂度：**O(n)**
   - 最坏情况：O(n)
   - 最好情况：O(n)
   - 平均情况：O(n)

**二、空间复杂度**

详细分析：

1. 位运算法：
   - 只使用一个 char 变量 → **O(1)**

2. 求和法：
   - 只使用一个 int 变量 → **O(1)**

3. 计数法：
   - 使用固定大小数组（26个int）→ **O(1)**（因为大小恒定）

4. 总空间复杂度：**O(1)**
   - 无论输入规模多大，使用的额外空间都是固定的
