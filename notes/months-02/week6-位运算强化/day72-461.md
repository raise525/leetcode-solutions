## #461 汉明距离

**【题目描述】**
两个整数之间的汉明距离指的是这两个数字对应二进制位不同的位置的数目。给定两个整数 x 和 y，计算并返回它们之间的汉明距离。

**【关键词】**
位运算 | 异或 | 二进制计数

---

**【核心技巧】**

#### 一、异或 + 位计数法（最优解）

**核心思想：**
1. 先对 x 和 y 进行异或运算：`xor = x ^ y`
2. 异或的结果中，某位为 1 表示 x 和 y 在该位上不同
3. 统计 `xor` 中 1 的个数，就是汉明距离

**为什么可行？**
- 异或运算：相同为 0，不同为 1
- `x ^ y` 的二进制表示中，每个 1 都代表 x 和 y 在该位不同
- 统计 1 的个数 = 不同位的个数 = 汉明距离

**代码实现（方法一：内置函数）：**
```c
int hammingDistance(int x, int y) {
    return __builtin_popcount(x ^ y);  // 一行搞定！
}
```



#### 二、逐位比较法

**核心思想：**
直接比较 x 和 y 的每一位，统计不同的位数，`因为是整数，所以只有32位，循环条件已经明确了`

**代码实现：**
```c
int hammingDistance(int x, int y) {
    int count = 0;
    for (int i = 0; i < 32; i++) {
        // 分别取 x 和 y 的第 i 位比较
        if (((x >> i) & 1) != ((y >> i) & 1)) {
            count++;
        }
    }
    return count;
}
```

**【复杂度分析】**

**一、时间复杂度**

详细分析：

1. 异或法：
   - `x ^ y`：O(1)
   - 统计1的个数：O(1)（最多32位）
   - 总时间：**O(1)**

2. 逐位比较法：
   - 循环32次，每次常数操作
   - 总时间：**O(1)**

3. 关键点：
   - 整数位数固定（32位或64位）
   - 无论数字多大，操作次数都是固定的

**二、空间复杂度**

详细分析：

1. 所有方法：
   - 只使用几个临时变量
   - 不随输入规模变化

2. 总空间复杂度：**O(1)**

---

**【位运算小技巧总结】**

1. **异或的性质**：
   - `x ^ x = 0`（相同为0）
   - `x ^ 0 = x`（与0异或不变）
   - `x ^ y` 的结果中，1的位置就是不同的位

2. **统计1的个数**：
   - 内置函数：`__builtin_popcount()`
   - 逐位检查：`(num >> i) & 1`
   - Brian算法：`num &= (num - 1)` 消除最低位的1

3. **取第i位**：`(num >> i) & 1`
