个人的思路过程：
1. 首先这是一个递归问题，所以我们要找到，递归的条件（n是n-1的行程编码长度）和出口（第一个为一）-> 递归也可以使用 循环迭代完成
2. 然后就需要求行程编码长度：次数 × 字符， 所以就是一个统计字符串中连续相同字符的个数， -> 双指针来统计个数，结束条件就是遍历完成

## #38 外观数列

**【题目描述】**
「外观数列」是一个数位字符串序列，由递归公式定义：

- countAndSay(1) = "1"
- countAndSay(n) 是 countAndSay(n-1) 的行程长度编码（RLE）

行程长度编码：将连续相同字符替换为「字符重复次数 + 字符」的形式。
例如："3322251" → "23" + "32" + "15" + "11" = "23321511"

给定一个整数 n，返回外观数列的第 n 个元素。

**【关键词】**
字符串 | 递归 | 迭代 | 双指针 | 行程长度编码

---

### **🧠 思维推导**

**由什么想到什么：**
```
外观数列 → 读前一项 → 需要遍历前一项字符串
     ↓
  统计连续字符 → 双指针 / 计数器
     ↓
  第 n 项依赖第 n-1 项 → 递归 / 迭代
     ↓
  数位字符串 → 注意数字拼接顺序
```

---

### **核心技巧**

#### 一、迭代法（双指针统计）

**核心思想：**
从 "1" 开始，依次生成下一项，直到第 n 项。

**解题步骤：**
1. 初始化当前项 cur = "1"
2. 循环 n-1 次生成下一项：
   - 遍历当前字符串，用双指针统计连续相同字符的个数
   - 将「个数 + 字符」拼接到下一项
3. 返回第 n 项

**代码实现：**
```cpp
string countAndSay(int n) {
    string cur = "1";
    
    for (int k = 2; k <= n; k++) {
        string next = "";
        int i = 0, j = 0;
        
        // 双指针统计连续字符
        while (i < cur.size()) {
            j = i;
            while (j < cur.size() && cur[j] == cur[i]) {
                j++;
            }
            // j - i 是连续个数，cur[i] 是字符
            next += to_string(j - i) + cur[i];
            i = j;
        }
        cur = next;
    }
    
    return cur;
}
```

**复杂度：**
- 时间复杂度：O(m×n)，m 是字符串长度（随 n 指数增长）
- 空间复杂度：O(m)

#### 二、递归法

**核心思想：**
直接按定义递归：countAndSay(n) 是对 countAndSay(n-1) 进行 RLE 编码。

**代码实现：**
```cpp
string countAndSay(int n) {
    if (n == 1) return "1";
    
    string prev = countAndSay(n - 1);
    string res = "";
    
    int i = 0;
    while (i < prev.size()) {
        int j = i;
        while (j < prev.size() && prev[j] == prev[i]) {
            j++;
        }
        res += to_string(j - i) + prev[i];
        i = j;
    }
    
    return res;
}
```

#### 三、正则表达式法（工程解法）

利用正则表达式匹配连续相同字符：
- Python 的 `re.findall(r'(.)\1*', s)` 可以找到所有连续段
- 然后对每段进行编码

**Python 示例：**
```python
import re

def countAndSay(self, n: int) -> str:
    s = "1"
    for _ in range(n - 1):
        # 匹配连续相同字符的组
        s = ''.join(str(len(group)) + group[0] 
                   for group in re.findall(r'(.)\1*', s))
    return s
```

**【复杂度分析】**

**一、时间复杂度**

1. **字符串长度增长：**
   - 第 n 项的长度约增长 30% 左右
   - 实际长度增长较复杂，近似指数增长

2. **操作次数：**
   - 需要生成 n-1 次
   - 每次遍历当前字符串，长度 L_k
   - 总操作 = L_2 + L_3 + ... + L_n

3. **总时间复杂度：** **O(λⁿ)**（指数级，λ ≈ 1.3）
   - 严格来说是指数时间复杂度
   - 但因为 n ≤ 30（题目限制），实际可行

**二、空间复杂度**

1. **迭代法：**
   - 需要存储当前项和下一项 → **O(L_n)**
   - L_n 是第 n 项的长度

2. **递归法：**
   - 递归深度 n → 栈空间 O(n)
   - 每层存储字符串 → 总空间 O(n × 平均长度)
