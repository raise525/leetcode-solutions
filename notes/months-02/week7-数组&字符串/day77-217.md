## #217 存在重复元素

**【题目描述】**
给你一个整数数组 nums。如果任一值在数组中出现至少两次，返回 true；如果数组中每个元素互不相同，返回 false。

**【关键词】**
哈希表 | 排序 | 集合 | 去重

---

### **🧠 思维推导**

**由什么想到什么：**
```
判断重复 → 需要记录出现过的元素 → 哈希表（空间换时间）
     ↓
  也可先排序 → 重复元素必相邻 → 排序+遍历（时间换空间）
     ↓
  集合去重 → 比较原数组和去重后的长度 → 最简洁
```

---

### **核心技巧**

#### 一、哈希表法（最直观）

**核心思想：**
遍历数组，用哈希表记录每个元素是否出现过，如果遇到已存在的元素则返回 true。

**解题步骤：**
1. 创建一个哈希集合（或哈希表）
2. 遍历数组中的每个元素
3. 如果当前元素已在集合中，返回 true
4. 否则将当前元素加入集合
5. 遍历结束返回 false

**代码实现：**
```cpp
bool containsDuplicate(vector<int>& nums) {
    unordered_set<int> seen;
    
    for (int num : nums) {
        if (seen.count(num)) {
            return true;
        }
        seen.insert(num);
    }
    return false;
}
```

#### 二、排序法

**核心思想：**
先对数组排序，重复元素在排序后会相邻，只需检查相邻元素是否相等。

**代码实现：**
```cpp
bool containsDuplicate(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    
    for (int i = 1; i < nums.size(); i++) {
        if (nums[i] == nums[i - 1]) {
            return true;
        }
    }
    return false;
}
```

#### 三、集合长度比较法（最简洁）

**核心思想：**
将数组转为集合（自动去重），比较集合长度与原数组长度。

**不同语言实现：**
```cpp
// C++
bool containsDuplicate(vector<int>& nums) {
    return unordered_set<int>(nums.begin(), nums.end()).size() < nums.size();
}
```

### **📊 复杂度分析（详细版）**

**一、哈希表法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历数组：n 次循环
   - 每次循环执行：
     * 一次哈希表查找操作（`.count()`）
     * 可能的一次哈希表插入操作（`.insert()`）
   
2. **哈希表操作分析：**
   - 平均情况下：O(1)
   - 最坏情况（哈希冲突严重）：O(n)
   - 但 C++ `unordered_set` 采用链地址法，负载因子合适时接近 O(1)

3. **总操作次数：**
   - 最好情况：找到重复时提前退出，可能只遍历前几个元素
   - 最坏情况：无重复，完整遍历 n 个元素 → n 次查找 + n 次插入
   - 平均情况：约 n/2 次查找（找到重复的平均位置）  
   - 平均遍历次数 = (2 + 3 + 4 + ... + n) / (n-1)  因为第二次出现的位置分别为2-n，一共n-1重可能

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 最坏情况（无重复）：存储所有 n 个元素
   - 每个元素在哈希表中存储为节点，包含：
     * 元素值本身（int，4/8 字节）
     * 哈希指针（8 字节）
     * 其他元数据
   - 实际内存约 16-24 字节/元素

2. **最好情况：** 第一个元素就重复，只需存储 1 个元素

3. **平均情况：** 约存储 n/2 个元素（找到重复时）

---

**二、排序法**

**时间复杂度：O(n log n)**

详细分析：
1. **排序阶段（主导因素）：**
   - C++ `sort()` 采用内省排序（快排+堆排）
   - 平均比较次数：O(n log n)
   - 最坏情况：O(n log n)（堆排保证）
   - 实际比较次数 ≈ n log₂n

2. **遍历阶段：**
   - n-1 次比较
   - 可忽略不计（O(n)）

3. **总操作：** n log₂n + n ≈ n log₂n

**空间复杂度：O(log n) 或 O(1)**

详细分析：
1. **排序空间：**
   - 快速排序递归深度：平均 O(log n)，最坏 O(n)
   - 但 C++ `sort()` 优化后：使用迭代而非递归，或限制递归深度
   - 实际额外空间 ≈ O(log n)

2. **原地排序：**
   - 不创建新数组
   - 只交换元素位置

---

**三、集合长度法**

**时间复杂度：O(n)**

详细分析：
1. **构造集合：**
   - 需要遍历整个数组插入到 unordered_set
   - n 次插入操作，每次平均 O(1)
   - 总时间 ≈ n

2. **比较长度：**
   - 取 size() 是 O(1)
   - 比较操作 O(1)

3. **缺点：**
   - 无法提前退出（必须完整遍历）
   - 即使第一个元素就重复，也要处理完所有元素

**空间复杂度：O(n)**

与哈希表法相同，必须存储所有不重复元素

---

**四、暴力法（补充分析）**

**时间复杂度：O(n²)**

详细分析：
1. **操作次数：**
   - 外层循环：i = 0 到 n-1
   - 内层循环：j = i+1 到 n-1
   - 总比较次数 = (n-1) + (n-2) + ... + 1 = n(n-1)/2

2. **具体数值：**
   - n=10: 45 次比较
   - n=100: 4950 次比较
   - n=1000: 约 50 万次比较
   - n=10⁴: 约 5000 万次比较

3. **增长率：** O(n²) 意味着 n 翻倍，时间变为 4 倍

**空间复杂度：O(1)**
只使用循环变量，无额外空间

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 哈希表 | O(n) | O(n) | 可提前退出，直观 | 额外空间大 |
| 排序 | O(n log n) | O(log n) | 空间效率高 | 修改原数组 |
| 集合长度 | O(n) | O(n) | 代码最简洁 | 无法提前退出 |
| 暴力 | O(n²) | O(1) | 无额外空间 | 极慢，不实用 |
