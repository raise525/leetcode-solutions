## 🎯 极简版：位运算五大核心公式

### **1️⃣ 异或三定律**
```
① a ^ a = 0        → 自己消自己
② a ^ 0 = a        → 0是空气
③ a ^ b ^ a = b    → 交换伴侣
```

### **2️⃣ n & (n-1) 两用途**
```
① 判断2的幂： (n & (n-1)) == 0  → 只有一个1
② 统计1个数： while(n){n&=n-1; cnt++}  → 消灭一个算一个
```

### **3️⃣ 掩码三板斧**
```
① 取低k位： n & ((1<<k)-1)
② 取第k位： (n >> k) & 1
③ 置1/清0： n | (1<<k)  /  n & ~(1<<k)
```

### **4️⃣ 加法器公式**
```
a + b = (a ^ b) + ((a & b) << 1)  // 无进位和 + 进位
        ↓ 循环直到进位=0
```

### **5️⃣ 幂次判断口诀**
```
2的幂：只有一个1，位置随便
4的幂：是2的幂，且1在奇数位（0x55555555）
```

## 💡 一句话总结

**位运算就是：**
- **异或**：找不同、做加法（不进位）
- **与**：找进位、取掩码
- **或**：置位、合并
- **左移右移**：搬家、乘除2
