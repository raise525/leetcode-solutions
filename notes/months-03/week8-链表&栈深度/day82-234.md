个人的思路：
1. 判断回文 → 一头一尾指针判断相同，但那是数组才能从后往前遍历，现在是链表 → 那我把链表的值用数组来存就好了，时间和空间都是O（n）
2. 我想只在链表上做（节省空间） → 基本思路不变，怎么从两边往中间判相同呢？（自己就卡死在这里）
3. 看题解之后的启发：重点还是，如何`从末尾往中间遍历`

## #234 回文链表

**【题目描述】**
给你一个单链表的头节点 head ，请你判断该链表是否为回文链表。如果是，返回 true ；否则，返回 false 。

**【关键词】**
链表 | 双指针 | 反转链表 | 栈 | 回文判断

---

### **🧠 思维推导**

**由什么想到什么：**
```
回文 → 正着读和反着读一样 → 需要比较前半段和反转后的后半段
     ↓
  单链表无法反向遍历 → 需要先找到中点
     ↓
  找中点 → 快慢指针（快指针走两步，慢指针走一步）
     ↓
  反转后半段 → 然后与前半段比较
     ↓
  注意：奇数长度时中间节点如何处理
```

---

### **核心技巧**

#### 一、快慢指针 + 反转后半段（最优解）

**核心思想：**
1. 用快慢指针找到链表的中点
2. 反转后半部分链表
3. 比较前半部分和反转后的后半部分
4. 恢复链表（可选）

**解题步骤：**
1. **找中点**：快指针走两步，慢指针走一步，快指针到达末尾时，慢指针到达中点
2. **反转后半段**：从中点开始反转后面的链表
3. **比较**：同时遍历前半段和反转后的后半段，比较节点值
4. **恢复**（可选）：将链表恢复原状

**代码实现：**
```cpp
bool isPalindrome(ListNode* head) {
    if (head == nullptr || head->next == nullptr) return true;
    
    // 1. 找到中点
    ListNode *slow = head, *fast = head;
    while (fast->next != nullptr && fast->next->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }
    
    // 2. 反转后半段
    ListNode *secondHalf = reverseList(slow->next);
    
    // 3. 比较
    ListNode *p1 = head, *p2 = secondHalf;
    bool result = true;
    while (p2 != nullptr) {
        if (p1->val != p2->val) {
            result = false;
            break;
        }
        p1 = p1->next;
        p2 = p2->next;
    }
    
    // 4. 恢复链表（可选）
    slow->next = reverseList(secondHalf);
    
    return result;
}

// 反转链表函数
ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *curr = head;
    while (curr != nullptr) {
        ListNode *nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 二、数组 + 双指针法

**核心思想：**
将链表值复制到数组中，然后用双指针从两端向中间比较。

**代码实现：**
```cpp
bool isPalindrome(ListNode* head) {
    vector<int> vals;
    
    // 将链表值存入数组
    ListNode* curr = head;
    while (curr != nullptr) {
        vals.push_back(curr->val);
        curr = curr->next;
    }
    
    // 双指针比较
    int left = 0, right = vals.size() - 1;
    while (left < right) {
        if (vals[left] != vals[right]) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 三、栈法

**核心思想：**
将前半段入栈，然后遍历后半段时与栈顶比较。

**代码实现：**
```cpp
bool isPalindrome(ListNode* head) {
    if (head == nullptr || head->next == nullptr) return true;
    
    // 先求长度
    int len = 0;
    ListNode* curr = head;
    while (curr != nullptr) {
        len++;
        curr = curr->next;
    }
    
    // 前半段入栈
    stack<int> st;
    curr = head;
    for (int i = 0; i < len / 2; i++) {
        st.push(curr->val);
        curr = curr->next;
    }
    
    // 如果奇数长度，跳过中间节点
    if (len % 2 == 1) {
        curr = curr->next;
    }
    
    // 比较
    while (curr != nullptr) {
        if (st.top() != curr->val) {
            return false;
        }
        st.pop();
        curr = curr->next;
    }
    
    return true;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n/2) = O(n)

#### 四、递归法

**核心思想：**
利用递归的回溯特性，用全局指针从前往后，递归从后往前比较。

**代码实现：**
```cpp
class Solution {
private:
    ListNode* frontPointer;
    
    bool recursivelyCheck(ListNode* currentNode) {
        if (currentNode != nullptr) {
            if (!recursivelyCheck(currentNode->next)) {
                return false;
            }
            if (currentNode->val != frontPointer->val) {
                return false;
            }
            frontPointer = frontPointer->next;
        }
        return true;
    }
    
public:
    bool isPalindrome(ListNode* head) {
        frontPointer = head;
        return recursivelyCheck(head);
    }
};
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)（递归栈）

### **📊 复杂度分析（详细版）**

**一、快慢指针 + 反转后半段法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 找中点：遍历 n/2 次
   - 反转后半段：遍历 n/2 次
   - 比较：遍历 n/2 次
   - 恢复（可选）：遍历 n/2 次
   - 总操作次数 ≈ 2n

2. **常数因子：**
   - 虽然有多次遍历，但每次都是部分遍历
   - 总时间 ≈ 2n，仍为 O(n)

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用几个指针变量（slow, fast, p1, p2, prev, curr）
   - 没有创建新节点
   - 所有操作在原链表上进行

2. **优势：** 真正的常数空间，是这道题的最优解

---

**二、数组法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历链表存入数组：n 次
   - 双指针比较：n/2 次
   - 总操作次数 ≈ 1.5n

2. **数组访问：** O(1) 随机访问，比较效率高

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 需要存储所有 n 个节点的值
   - 每个值 int 类型，4 或 8 字节
   - 总空间 ≈ n × 4/8 字节

2. **缺点：** 空间随 n 线性增长

---

**三、栈法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 第一次遍历求长度：n 次
   - 第二次遍历入栈：n/2 次
   - 第三次遍历比较：n/2 次
   - 总操作次数 ≈ 2n

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 栈中存储 n/2 个元素
   - 空间 ≈ n/2 × 元素大小

2. **比数组法略优：** 只存一半

---

**四、递归法**

**时间复杂度：O(n)**

详细分析：
1. **递归深度：** n
2. **每层操作：** O(1)
3. **总时间：** n × O(1) = O(n)

**空间复杂度：O(n)**

详细分析：
1. **递归栈：**
   - 递归深度为 n
   - 每层栈帧存储局部变量和返回地址
   - 总空间 ≈ n × 栈帧大小

2. **缺点：** 对于长链表可能栈溢出

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 快慢指针+反转 | O(n) | O(1) | 空间最优，不依赖额外结构 | 实现稍复杂，会修改链表 |
| 数组法 | O(n) | O(n) | 实现简单，直观 | 需要 O(n) 空间 |
| 栈法 | O(n) | O(n) | 只需存一半 | 需要两次遍历 |
| 递归法 | O(n) | O(n) | 代码简洁 | 栈溢出风险 |

### **🔍 示例推导**

**链表：1 → 2 → 3 → 2 → 1（回文）**

快慢指针找中点过程：
```
初始：slow=1, fast=1
第1步：slow=2, fast=3
第2步：slow=3, fast=1（fast->next->next 为空，停止）
中点：slow=3（中间节点）
```

反转后半段：
```
原后半段：3 → 2 → 1
反转后：1 → 2 → 3（注意：原链表结构已变）
```

比较：
```
前半段：1 → 2 → 3
后半段：1 → 2 → 3
全部相等 → 回文
```
