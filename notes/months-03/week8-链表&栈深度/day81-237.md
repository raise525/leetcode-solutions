## #237 删除链表中的节点

**【题目描述】**
有一个单链表的 head，我们想删除它其中的一个节点 node。给你一个需要删除的节点 node，你将无法访问第一个节点 head。链表的所有值都是唯一的，并且保证给定的节点 node 不是链表中的最后一个节点。

**【关键词】**
链表 | 节点删除 | 值替换 | 脑筋急转弯

---

### **🧠 思维推导**

**由什么想到什么：**
```
删除节点 → 通常需要前驱节点修改 next 指针
     ↓
  无法访问 head → 找不到前驱节点
     ↓
  特殊条件：node 不是尾节点 → 可以"狸猫换太子"
     ↓
  解法：将当前节点伪装成下一个节点，然后删除下一个节点
```

---

### **核心技巧**

#### 一、值替换法（狸猫换太子）

**核心思想：**
因为无法获取前驱节点，不能通过修改前驱的 next 指针来删除当前节点。但可以将当前节点的值替换为下一个节点的值，然后删除下一个节点。

**解题步骤：**
1. 将当前节点的值替换为下一个节点的值：`node.val = node.next.val`
2. 将当前节点的 next 指针指向下下个节点：`node.next = node.next.next`
3. 这样就相当于删除了当前节点（实际是删除了下一个节点，但值已经替换过来了）

**图解：**
```
删除前： A → B(node) → C → D
删除后： A → C → D
但实际上我们做的是：
1. 将 node 的值改为 C 的值：A → C(node) → C → D
2. 跳过下一个节点：A → C(node) → D
结果看起来就像删除了 B 节点
```

**代码实现：**
```cpp
void deleteNode(ListNode* node) {
    // 将当前节点的值替换为下一个节点的值
    node->val = node->next->val;
    // 跳过下一个节点
    node->next = node->next->next;
}
```

**复杂度：**
- 时间复杂度：O(1)
- 空间复杂度：O(1)

#### 二、指针重连法（另一种写法）

**核心思想：**
思路完全相同，只是写法略有不同。

**代码实现：**
```cpp
void deleteNode(ListNode* node) {
    ListNode* nextNode = node->next;
    node->val = nextNode->val;
    node->next = nextNode->next;
    // 可选：释放被删除节点的内存（C++需要手动管理）
    // delete nextNode;
}
```

---

### **📊 复杂度分析（详细版）**

**一、时间复杂度：O(1)**

详细分析：
1. **操作分解：**
   - 一次赋值操作：`node->val = node->next->val`
   - 一次指针操作：`node->next = node->next->next`
   - 总共 2 个基本操作

2. **为什么是常数时间：**
   - 不涉及循环
   - 不涉及递归
   - 无论链表多长，操作次数固定

**二、空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 没有创建新的节点
   - 最多使用一个临时指针（可选）
   - 所有操作在原链表上进行

2. **是否释放内存：**
   - C++ 中如果需要释放被"删除"节点的内存，需要额外操作
   - 但空间复杂度仍然是 O(1)，因为释放内存不占用额外空间

---

### **🔍 为什么这样可行？**

**常规删除 vs 本题删除**

常规删除节点 B：
```
A → B → C → D
需要找到 A，让 A.next = C
然后释放 B
```

本题情况：
```
无法访问 A，只能访问 B
但知道 B 不是尾节点（B.next 存在）
```

**关键洞察：**
- 我们无法真正删除 B 节点（因为没有前驱节点）
- 但我们可以让 B 节点"变成"C 节点，然后删除 C 节点
- 从结果上看，B 节点被"删除"了

**验证正确性：**
```
原链表：A(1) → B(2) → C(3) → D(4)
要删除节点 B(2)

操作后：
1. node->val = node->next->val  // B.val = 3
   A(1) → B(3) → C(3) → D(4)
2. node->next = node->next->next // B.next = D
   A(1) → B(3) → D(4)

结果链表：1 → 3 → 4
确实删除了值为 2 的节点
```

---

### **⚠️ 注意事项**

1. **题目保证 node 不是最后一个节点**
   - 这是解题的关键前提
   - 如果 node 是尾节点，`node->next` 为 nullptr，代码会出错

2. **值唯一性**
   - 题目保证值唯一，但即使值不唯一，这个方法也有效
   - 只是如果值不唯一，可能会有多个相同值的节点

3. **内存管理**
   - 在 C++ 中，被跳过的节点（原 node->next）实际上没有被释放
   - 如果要求严格的内存管理，需要手动 delete
   - 但题目通常不要求，只需要逻辑上删除

4. **实际应用**
   - 这种删除方式在某些场景下很有用
   - 比如在只知道节点指针，无法访问头节点的情况下
