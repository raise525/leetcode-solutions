个人的思路：
1. 本实质上就是删除，prev.next = curr.next 但是要考虑到head可能也要删除 -> 可以`单独循环处理`
2. 看到题解：想把头节点也一起处理 -> 本质上就是缺少了 head的prev 直接给他加一个`虚拟的头节点`就好了  && `递归处理`

## #203 移除链表元素

**【题目描述】**
给你一个链表的头节点 head 和一个整数 val ，请你删除链表中所有满足 Node.val == val 的节点，并返回新的头节点。

**【关键词】**
链表 | 虚拟头节点 | 双指针 | 递归

---

### **🧠 思维推导**

**由什么想到什么：**
```
删除指定值的节点 → 需要遍历链表找到这些节点
         ↓
  删除节点需要前驱节点 → 头节点可能被删除 → 需要特殊处理
         ↓
  统一处理技巧 → 使用虚拟头节点（dummy head）
         ↓
  或者用双指针 → prev 记录前驱，curr 遍历
```

---

### **核心技巧**

#### 一、虚拟头节点法（推荐）

**核心思想：**
创建一个虚拟头节点指向原链表头，这样原链表的头节点就有了前驱，可以统一删除逻辑。

**解题步骤：**
1. 创建虚拟头节点 dummy，dummy.next = head
2. 初始化指针 prev = dummy，curr = head
3. 遍历链表：
   - 如果 curr.val == val，则 prev.next = curr.next（删除当前节点）
   - 否则，prev = curr（移动 prev）
   - curr = curr.next（继续遍历）
4. 返回 dummy.next（新的头节点）

**代码实现：**
```cpp
ListNode* removeElements(ListNode* head, int val) {
    // 创建虚拟头节点
    ListNode* dummy = new ListNode(0);
    dummy->next = head;
    
    ListNode* prev = dummy;
    ListNode* curr = head;
    
    while (curr != nullptr) {
        if (curr->val == val) {
            // 删除当前节点
            prev->next = curr->next;
            delete curr;  // C++需要手动释放内存
            curr = prev->next;
        } else {
            // 移动指针
            prev = curr;
            curr = curr->next;
        }
    }
    
    ListNode* newHead = dummy->next;
    delete dummy;  // 释放虚拟头节点
    return newHead;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 二、双指针法（无虚拟头节点）

**核心思想：**
分别处理头节点和非头节点的情况。头节点需要特殊处理，因为头节点没有前驱。

**代码实现：**
```cpp
ListNode* removeElements(ListNode* head, int val) {
    // 处理头节点就是要删除的情况
    while (head != nullptr && head->val == val) {
        ListNode* temp = head;
        head = head->next;
        delete temp;
    }
    
    // 如果链表为空，直接返回
    if (head == nullptr) return nullptr;
    
    // 处理非头节点
    ListNode* prev = head;
    ListNode* curr = head->next;
    
    while (curr != nullptr) {
        if (curr->val == val) {
            prev->next = curr->next;
            delete curr;
            curr = prev->next;
        } else {
            prev = curr;
            curr = curr->next;
        }
    }
    
    return head;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 三、递归法

**核心思想：**
递归地处理链表：如果当前节点需要删除，则返回下一个节点的处理结果；否则保留当前节点，并递归处理下一个节点。

**代码实现：**
```cpp
ListNode* removeElements(ListNode* head, int val) {
    // 递归终止条件
    if (head == nullptr) return nullptr;
    
    // 递归处理后续节点
    head->next = removeElements(head->next, val);
    
    // 判断当前节点是否需要删除
    if (head->val == val) {
        ListNode* newHead = head->next;
        delete head;  // 释放内存
        return newHead;
    } else {
        return head;
    }
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)（递归栈）

---

### **📊 复杂度分析（详细版）**

**一、虚拟头节点法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历链表：n 次循环（n 为链表长度）
   - 每次循环执行：
     * 一次值比较
     * 可能的一次删除操作（指针修改）
     * 指针移动

2. **删除操作：**
   - 每个节点最多被检查一次
   - 每个节点最多被删除一次
   - 总操作次数 ≈ 2n（比较 + 指针操作）

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 创建了一个虚拟头节点（固定大小）
   - 两个指针变量 prev 和 curr
   - 所有操作在原链表上进行

2. **优点：** 真正的常数空间

---

**二、双指针法（无虚拟头节点）**

**时间复杂度：O(n)**

详细分析：
1. **头节点处理：**
   - 最坏情况：所有节点都要删除，需要多次处理头节点
   - 但每个节点仍只被访问一次

2. **遍历阶段：**
   - 与非头节点删除相同
   - 总操作次数 ≈ 2n

**空间复杂度：O(1)**
只使用指针变量，无额外空间

---

**三、递归法**

**时间复杂度：O(n)**

详细分析：
1. **递归深度：**
   - 递归深度为 n
   - 每层执行 O(1) 操作
   - 总时间 = n × O(1) = O(n)

**空间复杂度：O(n)**

详细分析：
1. **递归栈：**
   - 递归深度为 n
   - 每层栈帧存储局部变量和返回地址
   - 总空间 ≈ n × 栈帧大小

2. **缺点：** 对于长链表（如 n > 10⁵）可能导致栈溢出

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 虚拟头节点 | O(n) | O(1) | 统一删除逻辑，代码简洁 | 需要手动管理虚拟节点内存 |
| 双指针 | O(n) | O(1) | 无需额外节点 | 头节点需要特殊处理 |
| 递归 | O(n) | O(n) | 代码最简洁 | 栈溢出风险，空间大 |

### **🔍 示例推导**

**链表：1 → 2 → 6 → 3 → 4 → 5 → 6，val = 6**

虚拟头节点法过程：
```
初始：dummy → 1 → 2 → 6 → 3 → 4 → 5 → 6
      prev   curr

第1步：1 != 6 → prev=1, curr=2
第2步：2 != 6 → prev=2, curr=6
第3步：6 == 6 → 删除6：prev.next = curr.next (2→3)
      释放curr，curr=3
      链表：dummy → 1 → 2 → 3 → 4 → 5 → 6
第4步：3 != 6 → prev=3, curr=4
第5步：4 != 6 → prev=4, curr=5
第6步：5 != 6 → prev=5, curr=6
第7步：6 == 6 → 删除6：prev.next = curr.next (5→null)
      释放curr，curr=null
      链表：dummy → 1 → 2 → 3 → 4 → 5

结果：1 → 2 → 3 → 4 → 5
```

### **⚠️ 注意事项**

1. **内存管理（C++）**
   - 删除节点后需要手动释放内存
   - 虚拟头节点最后也需要释放

2. **连续删除**
   - 链表可能存在连续的需要删除的节点
   - 代码需要正确处理这种情况

3. **头节点删除**
   - 虚拟头节点法避免了头节点特殊处理
   - 双指针法则需要单独处理

4. **空链表**
   - 所有方法都需要处理 head == nullptr 的情况
