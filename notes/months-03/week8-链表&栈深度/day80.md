## #1290 二进制链表转整数

**【题目描述】**
给你一个单链表的引用结点 head。链表中每个结点的值不是 0 就是 1。已知此链表是一个整数数字的二进制表示形式。最高位在链表的头部。请你返回该链表所表示数字的十进制值。

**【关键词】**
链表 | 位运算 | 进制转换 | 遍历

---

### **🧠 思维推导**

**由什么想到什么：**
```
二进制转十进制 → 按位权展开求和 → 需要知道每一位的位权
         ↓
  最高位在头部 → 无法直接确定最低位权 → 需要先遍历到尾？
         ↓
  优化思路：边遍历边计算 → 每读一位，将当前结果左移一位再加上新位
         ↓
  公式：res = res * 2 + val  (秦九韶算法/霍纳方法)
```

---

### **核心技巧**

#### 一、遍历累加法（秦九韶算法）

**核心思想：**
每遍历一个节点，将当前结果左移一位（乘以2），再加上当前节点的值。这样不需要预先知道链表长度。

**数学原理：**
二进制数 1011 = ((1×2 + 0)×2 + 1)×2 + 1
- 第1步：1 → 1
- 第2步：1×2 + 0 = 2
- 第3步：2×2 + 1 = 5
- 第4步：5×2 + 1 = 11

**解题步骤：**
1. 初始化结果 res = 0
2. 遍历链表每个节点
3. 对于每个节点：res = res × 2 + node.val
4. 返回 res

**代码实现：**
```cpp
int getDecimalValue(ListNode* head) {
    int res = 0;
    ListNode* curr = head;
    
    while (curr != nullptr) {
        res = res * 2 + curr->val;
        curr = curr->next;
    }
    
    return res;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

#### 二、位运算法

**核心思想：**
用位运算替代乘法，左移一位等价于乘以2，再按位或等价于加法。

**代码实现：**
```cpp
int getDecimalValue(ListNode* head) {
    int res = 0;
    ListNode* curr = head;
    
    while (curr != nullptr) {
        res = (res << 1) | curr->val;
        curr = curr->next;
    }
    
    return res;
}
```

**为什么用位运算：**
- `res << 1`：左移一位，相当于乘以2
- `| curr->val`：将最低位设置为当前值（因为当前值只能是0或1）

#### 三、先求长度法（不推荐）

**核心思想：**
先遍历一遍求链表长度，知道最高位的位权，再从高位到低位累加。

**代码实现：**
```cpp
int getDecimalValue(ListNode* head) {
    // 先求长度
    int len = 0;
    ListNode* curr = head;
    while (curr != nullptr) {
        len++;
        curr = curr->next;
    }
    
    // 再计算值
    int res = 0;
    curr = head;
    while (curr != nullptr) {
        len--;
        res += curr->val * (1 << len);
        curr = curr->next;
    }
    
    return res;
}
```

**复杂度：**
- 时间复杂度：O(n)（但需要两次遍历）
- 空间复杂度：O(1)

---

### **📊 复杂度分析（详细版）**

**一、遍历累加法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历链表：n 次循环（n 为链表长度）
   - 每次循环执行：
     * 一次乘法（乘以2）
     * 一次加法（加当前值）
     * 指针后移

2. **乘法操作：**
   - 乘以2在计算机中实际是左移，O(1)
   - 但随着 res 变大，乘法可能涉及更多位，但对于固定位数整数仍是常数时间

3. **总操作次数：**
   - 无论链表多长，都恰好遍历 n 次
   - 无法提前终止（必须读完所有位）

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用一个 int 变量 res
   - 一个指针变量 curr
   - 固定大小，与链表长度无关

2. **优点：** 真正的常数空间

---

**二、位运算法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历链表：n 次循环
   - 每次循环执行：
     * 一次左移运算（<<）
     * 一次按位或运算（|）
     * 指针后移

2. **与累加法对比：**
   - 位运算通常比算术运算更快
   - 左移和按位或都是 CPU 单周期指令
   - 但宏观上仍是 O(n)

**空间复杂度：O(1)**
与累加法相同

---

**三、先求长度法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 第一次遍历：n 次循环，求长度
   - 第二次遍历：n 次循环，计算值
   - 总操作次数：2n

2. **常数因子：**
   - 比前两种方法多一倍的时间
   - 但复杂度仍为 O(n)

**空间复杂度：O(1)**
只使用变量，常数空间

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 遍历次数 | 优点 | 缺点 |
|------|-----------|-----------|---------|------|------|
| 遍历累加 | O(n) | O(1) | 1次 | 一次遍历，直观 | 需理解秦九韶算法 |
| 位运算 | O(n) | O(1) | 1次 | 效率最高，代码简洁 | 需理解位运算 |
| 先求长度 | O(n) | O(1) | 2次 | 思维直接 | 多一次遍历 |

---

### **🔍 示例推导**

**链表：1 → 0 → 1 → 1（二进制 1011）**

**遍历累加法过程：**
```
初始：res = 0
第1步：res = 0 × 2 + 1 = 1
第2步：res = 1 × 2 + 0 = 2
第3步：res = 2 × 2 + 1 = 5
第4步：res = 5 × 2 + 1 = 11
结果：11
```

**位运算法过程：**
```
初始：res = 0 (二进制 0000)
第1步：res = (0000 << 1) | 1 = 0001 = 1
第2步：res = (0001 << 1) | 0 = 0010 = 2
第3步：res = (0010 << 1) | 1 = 0101 = 5
第4步：res = (0101 << 1) | 1 = 1011 = 11
结果：11
```
