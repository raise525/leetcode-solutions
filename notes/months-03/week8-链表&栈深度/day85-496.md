个人的思路：
1. 整个流程很简单：先在num2中找到位置（定位），然后再往右遍历，找有没有更大的，记录它们的值，但是时间O（n*m）
2. 题解说：可以看成两个问题：
   - 首先是找出：num2元素的下一个更大元素（单调栈：可以从左到右遍历入栈，只要比栈顶更大就弹出，记录对应元素就行了）

## #496 下一个更大元素 I

**【题目描述】**
给你两个没有重复元素的数组 nums1 和 nums2，其中 nums1 是 nums2 的子集。对于 nums1 中的每个元素，找出它在 nums2 中对应位置右侧的第一个比它大的元素。如果不存在，则答案为 -1。返回长度为 nums1.length 的答案数组。

**【关键词】**
单调栈 | 哈希表 | 下一个更大元素

---

### **🧠 思维推导**

**由什么想到什么：**
```
找下一个更大元素 → 经典单调栈问题
         ↓
  需要快速定位 nums1 元素在 nums2 中的位置 → 哈希表记录索引
         ↓
  先预处理 nums2，计算每个元素的下一个更大元素 → 存入哈希表
         ↓
  然后遍历 nums1，直接从哈希表获取答案
```

---

### **核心技巧**

#### 一、单调栈 + 哈希表（最优解）

**核心思想：**
1. 先遍历 nums2，用单调栈找出每个元素的下一个更大元素，存入哈希表
2. 再遍历 nums1，直接从哈希表获取结果

**单调栈维护规则：**
- 维护一个单调递减栈（栈底到栈顶递减）
- 遍历 nums2 的每个元素 num：
  - 当栈非空且当前元素 > 栈顶元素时，说明当前元素是栈顶元素的下一个更大元素
  - 弹出栈顶，记录到哈希表
  - 将当前元素入栈
- 遍历结束后，栈中剩余的元素没有下一个更大元素，对应值为 -1

**解题步骤：**
1. 创建哈希表 map，用于存储 nums2 中每个元素的下一个更大元素
2. 创建单调栈 stack
3. 遍历 nums2：
   - while 栈非空且当前元素 > 栈顶元素：
     - map[栈顶元素] = 当前元素
     - 弹出栈顶
   - 将当前元素入栈
4. 遍历结束后，栈中剩余元素在 map 中值为 -1（可默认处理）
5. 遍历 nums1，从 map 中获取结果

**代码实现：**
```cpp
vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
    unordered_map<int, int> nextGreater;  // 存储每个元素的下一个更大元素
    stack<int> st;  // 单调递减栈
    
    // 预处理 nums2
    for (int num : nums2) {
        // 当前元素作为栈顶元素的下一个更大元素
        while (!st.empty() && num > st.top()) {
            nextGreater[st.top()] = num;
            st.pop();
        }
        st.push(num);
    }
    
    // 栈中剩余元素没有下一个更大元素
    // nextGreater 默认值为 0，但我们需要 -1，所以需要处理
    // 可以在获取时判断
    
    // 构建答案
    vector<int> ans;
    for (int num : nums1) {
        if (nextGreater.count(num)) {
            ans.push_back(nextGreater[num]);
        } else {
            ans.push_back(-1);
        }
    }
    return ans;
}
```

**复杂度：**
- 时间复杂度：O(n + m)，n 为 nums2 长度，m 为 nums1 长度
- 空间复杂度：O(n)

---

#### 二、暴力法

**核心思想：**
对于 nums1 的每个元素，先在 nums2 中找到它的位置，然后向右搜索第一个更大的元素。

**代码实现：**
```cpp
vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
    vector<int> ans;
    
    for (int num : nums1) {
        // 在 nums2 中找到 num 的位置
        int j = 0;
        while (j < nums2.size() && nums2[j] != num) {
            j++;
        }
        
        // 向右搜索第一个更大的元素
        int greater = -1;
        for (int k = j + 1; k < nums2.size(); k++) {
            if (nums2[k] > num) {
                greater = nums2[k];
                break;
            }
        }
        
        ans.push_back(greater);
    }
    
    return ans;
}
```

**复杂度：**
- 时间复杂度：O(m × n)，最坏情况 O(n²)
- 空间复杂度：O(1)（不含输出数组）

---

#### 三、哈希表记录索引 + 暴力搜索

**核心思想：**
先用哈希表记录 nums2 中每个元素的索引，然后对 nums1 的每个元素，从该索引开始向右搜索。

**代码实现：**
```cpp
vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
    unordered_map<int, int> indexMap;
    for (int i = 0; i < nums2.size(); i++) {
        indexMap[nums2[i]] = i;
    }
    
    vector<int> ans;
    for (int num : nums1) {
        int idx = indexMap[num];
        int greater = -1;
        for (int j = idx + 1; j < nums2.size(); j++) {
            if (nums2[j] > num) {
                greater = nums2[j];
                break;
            }
        }
        ans.push_back(greater);
    }
    
    return ans;
}
```

**复杂度：**
- 时间复杂度：O(m × n)，但查找索引是 O(1)
- 空间复杂度：O(n)

---

### **📊 复杂度分析（详细版）**

**一、单调栈 + 哈希表法**

**时间复杂度：O(n + m)**

详细分析：
1. **预处理阶段（遍历 nums2）：**
   - 每个元素最多入栈一次，出栈一次
   - 总操作次数 ≈ 2n
   - 所以是 O(n)

2. **构建答案阶段（遍历 nums1）：**
   - 遍历 m 个元素
   - 每次哈希表查询 O(1)
   - 所以是 O(m)

3. **总时间：** O(n) + O(m) = O(n + m)

**空间复杂度：O(n)**

详细分析：
1. **哈希表：**
   - 存储 nums2 中每个元素的下一个更大元素
   - 最多 n 个键值对
   - 空间 O(n)

2. **单调栈：**
   - 最坏情况（nums2 递减），栈中存储所有 n 个元素
   - 空间 O(n)

3. **总空间：** O(n) + O(n) = O(n)

---

**二、暴力法**

**时间复杂度：O(m × n)**

详细分析：
1. **外层循环：** m 次（nums1 长度）
2. **内层循环：**
   - 查找位置：最多 n 次
   - 搜索更大元素：最多 n 次
   - 每轮最多 2n 次操作

3. **最坏情况：**
   - nums1 = nums2（m = n）
   - 总操作 ≈ n × 2n = 2n²
   - 所以是 O(n²)

**空间复杂度：O(1)**
只使用几个变量，不含输出数组

---

**三、哈希表索引法**

**时间复杂度：O(m × n)**

详细分析：
1. **预处理：** O(n) 建立索引表
2. **查询阶段：**
   - 查找索引：O(1)
   - 搜索更大元素：最坏 O(n)
   - 每轮最多 O(n)

3. **最坏情况：** O(m × n)，与暴力法相同
4. **常数优化：** 比纯暴力法少了一次查找位置的过程

**空间复杂度：O(n)**
存储索引表

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 单调栈+哈希表 | O(n + m) | O(n) | 最优时间，一次预处理 | 需要理解单调栈 |
| 暴力法 | O(m × n) | O(1) | 空间最优，实现简单 | 时间效率低 |
| 哈希表索引 | O(m × n) | O(n) | 比暴力法稍快 | 仍需 O(n²) 时间 |

### **🔍 单调栈原理详解**

**为什么叫单调栈？**
栈内元素保持单调递减（从栈底到栈顶）

**工作过程示例：**
```
nums2 = [1, 3, 4, 2]

遍历过程：
1. num=1: 栈空 → 入栈 [1]
2. num=3: 3 > 1 → 1的下一个更大元素是3，记录 map[1]=3，弹出1，入栈 [3]
3. num=4: 4 > 3 → 3的下一个更大元素是4，记录 map[3]=4，弹出3，入栈 [4]
4. num=2: 2 < 4 → 直接入栈 [4,2]

结束：栈中剩余 [4,2] 没有下一个更大元素

结果：
1 → 3
3 → 4
4 → -1
2 → -1
```

**核心思想：**
- 栈中维护的是"还没有找到下一个更大元素"的元素
- 当遇到一个较大的数时，它就能成为栈中比它小的元素的下一个更大元素
