## #88 合并有序数组

**【题目描述】**
给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。

请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。

注意：最终，合并后数组不应由函数返回，而是`存储在数组 nums1 中`。为了应对这种情况，nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0 ，应忽略。nums2 的长度为 n 。

**【关键词】**
双指针

**【核心技巧】**
因为两个本来就是有序的，所以从后面开始比较，谁大谁就站最后一个位子，以此类推即可，`从后向前遍历可以避免在原数组操作时，覆盖掉某些元素`

- 当 len1 >= 0 && len2 >= 0 时，比较两个数组当前最大的元素，将较大的放入末尾
- 循环结束后，如果 nums2 还有剩余元素（len2 >= 0），说明这些是全局最小的元素，直接复制到 nums1 开头
- 如果 nums1 有剩余元素，它们已经在正确的位置，不需要移动
