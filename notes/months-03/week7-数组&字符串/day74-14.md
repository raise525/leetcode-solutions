## #14 最长公共前缀

**【题目描述】**
编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 ""。

**【关键词】**
字符串 | 横向扫描 | 纵向扫描 | 分治

---

### **🧠 思维推导**

**由什么想到什么：**
```
公共前缀 → 从开头算起 → 逐列比较 → 以第一个为基准（纵向扫描）
              ↓
        两两比较 → 逐步缩小（横向扫描）
              ↓
        分而治之 → 左右合并（分治法）
              ↓
        长度单调 → 二分猜测（二分法）
```

---

### **核心技巧**

#### 一、纵向扫描（最直观）

**核心思想：**
从第一个字符开始，依次比较所有字符串的同一列字符，直到遇到不匹配或某个字符串长度不够。

**解题步骤：**
1. 取第一个字符串作为基准
2. 遍历基准字符串的每个字符
3. 对于每个位置 i，检查其他所有字符串在位置 i 的字符是否与基准相同
4. 如果都相同，继续下一个位置；否则返回已找到的前缀

**代码实现：**
```cpp
string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    
    for (int i = 0; i < strs[0].size(); i++) {
        char c = strs[0][i];
        for (int j = 1; j < strs.size(); j++) {
            if (i >= strs[j].size() || strs[j][i] != c) {
                return strs[0].substr(0, i);
            }
        }
    }
    return strs[0];
}
```

#### 二、横向扫描（两两比较）

**核心思想：**
两两比较字符串，更新公共前缀，最终得到所有字符串的公共前缀。

**代码实现：**
```cpp
string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    
    string prefix = strs[0];
    for (int i = 1; i < strs.size(); i++) {
        while (strs[i].find(prefix) != 0) {
            prefix = prefix.substr(0, prefix.length() - 1);
            if (prefix.empty()) return "";
        }
    }
    return prefix;
}
```

#### 三、分治法（高级技巧）

**核心思想：**
将问题分解为求左右两半的公共前缀，再合并结果。

**代码实现：**
```cpp
string longestCommonPrefix(vector<string>& strs, int l, int r) {
    if (l == r) return strs[l];
    int mid = (l + r) / 2;
    string left = longestCommonPrefix(strs, l, mid);
    string right = longestCommonPrefix(strs, mid + 1, r);
    return commonPrefix(left, right);
}

string commonPrefix(string left, string right) {
    int minLen = min(left.length(), right.length());
    for (int i = 0; i < minLen; i++) {
        if (left[i] != right[i]) {
            return left.substr(0, i);
        }
    }
    return left.substr(0, minLen);
}
```

#### 四、二分查找法

**核心思想：**
对最短字符串的长度进行二分查找，判断某个长度的前缀是否是公共前缀。

**代码实现：**
```cpp
string longestCommonPrefix(vector<string>& strs) {
    if (strs.empty()) return "";
    
    int minLen = INT_MAX;
    for (string s : strs) {
        minLen = min(minLen, (int)s.length());
    }
    
    int low = 1, high = minLen;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (isCommonPrefix(strs, mid)) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    return strs[0].substr(0, (low + high) / 2);
}

bool isCommonPrefix(vector<string>& strs, int len) {
    string prefix = strs[0].substr(0, len);
    for (int i = 1; i < strs.size(); i++) {
        if (strs[i].substr(0, len) != prefix) {
            return false;
        }
    }
    return true;
}
```

**【复杂度分析】**

**一、时间复杂度**

详细分析（以纵向扫描为例）：

1. 操作次数：
   - 外层循环：遍历第一个字符串的每个字符，最多 m 次（m 是最短字符串长度）
   - 内层循环：遍历剩余 n-1 个字符串
   - 总操作次数 ≤ m × (n-1)

2. 关键点：
   - 最坏情况：所有字符串相同，需要完整遍历 → O(m×n)
   - 最好情况：第一个字符就不匹配 → O(n)
   - 平均情况：取决于数据分布

3. 各方法时间复杂度：
   - 纵向扫描：**O(m×n)**
   - 横向扫描：**O(m×n)**（但常数因子略大）
   - 分治法：**O(m×n)**（T(n) = 2T(n/2) + O(m)）
   - 二分法：**O(m×n×log m)**

**二、空间复杂度**

详细分析：

1. 纵向扫描：
   - 只使用几个变量 → **O(1)**

2. 横向扫描：
   - 使用一个字符串存储前缀 → **O(m)**（m 是前缀长度）

3. 分治法：
   - 递归深度 O(log n)，每层存储临时字符串 → **O(m×log n)**

4. 二分法：
   - 使用几个变量 → **O(1)**

**【个人的感受】**
1. 纵向扫描最容易理解，代码也最简洁，是面试的首选方案
2. 横向扫描的逻辑更符合人类的思维方式："先拿两个比，结果再跟第三个比"
3. 分治法和二分法虽然复杂度理论上有优势，但实际因为字符串操作的常数较大，不一定更快
4. 关键是要考虑空数组的边界情况，以及数组中有空字符串的情况
5. 这道题看似简单，但考察了多种算法思想：扫描、分治、二分，是一道很好的基础题
6. 今天做题想到了要逐位比较，但是卡死在想要所有字符串一起比较了，`两两比较是一个值得学习的思路`
