## #28 找出字符串中第一个匹配项的下标

**【题目描述】**
给你两个字符串 haystack 和 needle，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1。

**【关键词】**
字符串匹配 | KMP | 滑动窗口 | 双指针

---

### **🧠 思维推导**

**由什么想到什么：**
```
找子串位置 → 暴力解法 → 双重循环匹配（BF算法）
       ↓
  匹配过程有重复 → 利用已匹配信息 → KMP算法（next数组）
       ↓
  Java/C++内置 → indexOf() / find() （工程解法）
       ↓
  Python切片 → 直接比较子串（切片解法）
```

---

### **核心技巧**

#### 一、BF算法（暴力匹配，Brute Force）

**核心思想：**
从 haystack 的每个位置开始，尝试与 needle 进行匹配，如果完全匹配则返回当前位置。

**解题步骤：**
1. 遍历 haystack 的每个字符作为起始位置
2. 从起始位置开始，逐个字符与 needle 比较
3. 如果完全匹配，返回起始下标
4. 如果遍历完仍未找到，返回 -1

**代码实现：**
```cpp
int strStr(string haystack, string needle) {
    int n = haystack.size(), m = needle.size();
    
    for (int i = 0; i <= n - m; i++) {
        int j = 0;
        while (j < m && haystack[i + j] == needle[j]) {
            j++;
        }
        if (j == m) {
            return i;
        }
    }
    return -1;
}
```

**复杂度：**
- 时间复杂度：O(n×m)，最坏情况（如 haystack="aaaaaab", needle="aab"）
- 空间复杂度：O(1)

#### 二、KMP算法（Knuth-Morris-Pratt）

**核心思想：**
当匹配失败时，利用已匹配的信息，让 needle 尽量少回退，通过 next 数组记录最长公共前后缀长度。

**解题步骤：**
1. 构建 next 数组（部分匹配表）
2. 用双指针进行匹配
3. 匹配失败时，根据 next 数组移动 needle 指针

**代码实现：**
```cpp
int strStr(string haystack, string needle) {
    int n = haystack.size(), m = needle.size();
    if (m == 0) return 0;
    
    // 构建 next 数组
    vector<int> next(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && needle[i] != needle[j]) {
            j = next[j - 1];
        }
        if (needle[i] == needle[j]) {
            j++;
        }
        next[i] = j;
    }
    
    // KMP 匹配
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && haystack[i] != needle[j]) {
            j = next[j - 1];
        }
        if (haystack[i] == needle[j]) {
            j++;
        }
        if (j == m) {
            return i - m + 1;
        }
    }
    return -1;
}
```

**复杂度：**
- 时间复杂度：O(n + m)
- 空间复杂度：O(m)

#### 三、双指针滑动窗口

**核心思想：**
固定窗口大小为 needle 的长度，用双指针检查每个窗口是否匹配。

**代码实现：**
```cpp
int strStr(string haystack, string needle) {
    int n = haystack.size(), m = needle.size();
    
    for (int left = 0; left <= n - m; left++) {
        int right = 0;
        while (right < m && haystack[left + right] == needle[right]) {
            right++;
        }
        if (right == m) return left;
    }
    return -1;
}
```

#### 四、内置函数法（工程解法）

不同语言的字符串查找函数：
- C++：`haystack.find(needle)`
- Java：`haystack.indexOf(needle)`
- Python：`haystack.find(needle)`

**Python 示例：**
```python
def strStr(self, haystack: str, needle: str) -> int:
    return haystack.find(needle)
```

---

**【复杂度分析】**

**一、时间复杂度**

1. **BF算法：**
   - 最好情况：O(m)，第一个位置就匹配
   - 最坏情况：O(n×m)，如 "aaaaaab" 中找 "aab"
   - 平均情况：O(n + m)（实际通常接近线性）

2. **KMP算法：**
   - 构建 next 数组：O(m)
   - 匹配过程：O(n)
   - 总时间复杂度：**O(n + m)**

3. **滑动窗口：** O(n×m)（与 BF 本质相同）

**二、空间复杂度**

1. **BF算法：** O(1)
2. **KMP算法：** O(m)（存储 next 数组）
3. **滑动窗口：** O(1)

### **🧠 思维推导（详细版）**

**第1层：理解问题**
```
"在 haystack 中找 needle 第一次出现的位置"
    ↓
本质上就是实现一个字符串匹配函数
    ↓
手工怎么找？ → 从第一个字符开始，一个一个往后对
```

**第2层：手工模拟**
```
haystack = "hello", needle = "ll"

手算过程：
位置0: h vs l ❌
位置1: e vs l ❌
位置2: l vs l ✓ → 继续比下一个
位置3: l vs l ✓ → 全部匹配成功！返回位置2

发现规律：需要两个指针
- i：指向 haystack 的起始位置
- j：指向 needle 的当前位置
```

**第3层：翻译成代码（BF算法）**
```
由手工模拟
    ↓
想到"双重循环"
    ↓
外层循环：枚举 haystack 的每个起始位置 i
内层循环：比较 haystack[i+j] 和 needle[j]
    ↓
匹配成功：j 走到末尾 → 返回 i
匹配失败：跳出内层循环，i 移到下一位
```

**第4层：发现 BF 的问题**
```
haystack = "aaaaaaaaab", needle = "aaab"

BF 的过程：
i=0: 比较到第4位才失败，i 回退到1重新比
i=1: 又比较到第4位失败，i 回退到2...
    ↓
每次失败都要从头比，太浪费了！
    ↓
能不能利用已匹配的信息？
```

**第5层：观察已匹配的信息**
```
以 i=0 为例：
已匹配："aaa" 和 "aaa" 是相同的
    ↓
下次匹配时，能不能直接用这个信息？
    ↓
发现规律：needle 的前缀和后缀有重复
    ↓
比如 "aaa" 的前缀 "a" 和后缀 "a" 相同
    ↓
可以利用这个跳过一些比较
```

**第6层：抽象出 next 数组（KMP 的核心）**
```
由"已匹配部分的前后缀重复"
    ↓
想到"预处理 needle，记录每个位置的最长公共前后缀长度"
    ↓
这就是 next 数组：
next[j] 表示 needle[0..j] 中，最长公共前后缀的长度
    ↓
当匹配失败时，j 直接跳到 next[j-1]，不用从头开始
```

**第7层：KMP 的实现思路**
```
第一步：构建 next 数组（理解 needle 自己和自己匹配）
    ↓
第二步：用双指针匹配，失败时根据 next 跳转
    ↓
匹配成功 → 返回 i - m + 1
    ↓
匹配完整个 haystack 都没找到 → 返回 -1
```

### **完整思维链条总结**

```
问题 → 手工模拟 → 双重循环 → BF算法
    ↓
发现问题：重复比较太多
    ↓
观察规律：已匹配部分有重复模式
    ↓
抽象概念：公共前后缀
    ↓
预处理：next数组记录跳转信息
    ↓
优化匹配：失败时跳转而不回退
    ↓
最终得到：KMP算法
```

- **为什么 BF 效率低**（重复比较）
- **为什么想到 KMP**（想优化重复比较）
- **为什么用 next 数组**（记录跳转信息）
