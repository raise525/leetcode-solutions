个人的思路：
1. 这里是找一个没有出现的数字 -> 相当于查找，可以用哈希表 -> 用一个数组来做哈希表，出现的数字就把对应的下标置为一，最后便历一下就好了 O（n）
2. 但是这里也相当于，`找不同，可以用异或`

## #268 丢失的数字

**【题目描述】**
给定一个包含 [0, n] 中 n 个数的数组 nums，找出 [0, n] 这个范围内没有出现在数组中的那个数。

**【关键词】**
位运算 | 数学求和 | 哈希表 | 原地标记

---

### **🧠 思维推导**

**由什么想到什么：**
```
[0, n] 范围有 n+1 个数，数组只有 n 个数 → 少一个数
         ↓
  已知总和公式 → 用总和减去数组和 → 差值就是缺失的数
         ↓
  异或运算性质 → 每个数和自身异或为0 → 将所有数与下标异或
         ↓
  也可用哈希表记录出现过的数 → 再遍历找缺失
```

---

### **核心技巧**

#### 一、数学求和法（最直观）

**核心思想：**
[0, n] 的总和可以用公式 n*(n+1)/2 计算，减去数组中所有数的和，差值就是缺失的数字。

**解题步骤：**
1. 计算 [0, n] 的理论总和：total = n * (n + 1) / 2
2. 计算数组中所有数的和：sum
3. 缺失的数 = total - sum

**代码实现：**
```cpp
int missingNumber(vector<int>& nums) {
    int n = nums.size();
    int total = n * (n + 1) / 2;
    int sum = 0;
    
    for (int num : nums) {
        sum += num;
    }
    
    return total - sum;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**注意：** 当 n 很大时，n*(n+1)/2 可能溢出，可以用 long 类型，或者用异或法避免溢出。

---

#### 二、位运算法（异或）

**核心思想：**
利用异或的性质：a ^ a = 0，a ^ 0 = a。将 0 到 n 的所有数字与数组中的每个数字进行异或，出现两次的会抵消，最后剩下的就是缺失的数字。

**推导：**
```
设 missing 为缺失的数
将 0..n 全部异或：0^1^2^...^n
再将数组所有数异或：nums[0]^nums[1]^...^nums[n-1]
两个结果异或起来：
(0^1^...^n) ^ (nums[0]^...^nums[n-1])
= (0^0) ^ (1^1) ^ ... ^ missing ^ ... (缺失的数只出现一次)
= missing
```

**代码实现：**
```cpp
int missingNumber(vector<int>& nums) {
    int missing = nums.size();  // 先异或 n
    
    for (int i = 0; i < nums.size(); i++) {
        missing ^= i ^ nums[i];
    }
    
    return missing;
}
```

**另一种写法：**
```cpp
int missingNumber(vector<int>& nums) {
    int result = 0;
    
    // 先异或所有下标
    for (int i = 0; i <= nums.size(); i++) {
        result ^= i;
    }
    
    // 再异或所有数组元素
    for (int num : nums) {
        result ^= num;
    }
    
    return result;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- **优点：** 不会溢出，纯位运算效率高

---

#### 三、哈希表法

**核心思想：**
用哈希集合记录数组中出现的所有数，然后遍历 [0, n] 找到不在集合中的数。

**代码实现：**
```cpp
int missingNumber(vector<int>& nums) {
    unordered_set<int> set;
    
    for (int num : nums) {
        set.insert(num);
    }
    
    for (int i = 0; i <= nums.size(); i++) {
        if (set.find(i) == set.end()) {
            return i;
        }
    }
    
    return -1;  // 不会执行到这里
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 四、排序法

**核心思想：**
先对数组排序，然后遍历检查相邻元素是否连续，找到缺失的位置。

**代码实现：**
```cpp
int missingNumber(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    
    // 检查每个位置是否等于下标
    for (int i = 0; i < nums.size(); i++) {
        if (nums[i] != i) {
            return i;
        }
    }
    
    // 如果都相等，缺失的是 n
    return nums.size();
}
```

**复杂度：**
- 时间复杂度：O(n log n)（排序时间）
- 空间复杂度：O(1)（原地排序）

---

#### 五、原地标记法（负数标记）

**核心思想：**
利用数组原地标记已经出现过的数，将对应下标位置的值变为负数。

**代码实现：**
```cpp
int missingNumber(vector<int>& nums) {
    int n = nums.size();
    
    // 将所有出现的数对应的下标位置标记为负数
    for (int i = 0; i < n; i++) {
        int val = abs(nums[i]);  // 取绝对值，因为可能已被标记
        if (val < n) {  // n 这个值不需要标记（因为下标只到 n-1）
            nums[val] = -nums[val];
        }
    }
    
    // 找第一个非负数的位置
    for (int i = 0; i < n; i++) {
        if (nums[i] >= 0) {
            return i;
        }
    }
    
    // 如果所有位置都被标记，缺失的是 n
    return n;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- **注意：** 这种方法会修改原数组，需要确认是否允许

---

### **📊 复杂度分析（详细版）**

**一、数学求和法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 一次遍历数组求和：n 次加法
   - 一次公式计算：O(1)
   - 一次减法：O(1)

2. **总操作次数：** n + 常数 ≈ O(n)

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用两个变量 total 和 sum
   - 固定大小，与 n 无关

**潜在问题：**
- 当 n 很大时（如 n = 2^31-1），n*(n+1)/2 可能溢出 32 位整数
- 解决方案：使用 long long 或改用异或法

---

**二、位运算法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 一次遍历：n 次循环
   - 每次循环：两次异或操作
   - 总操作 ≈ 2n 次位运算

2. **效率：** 位运算比算术运算更快

**空间复杂度：O(1)**
只使用一个变量 result

**优点：**
- 不会溢出
- 纯位运算，效率高
- 不修改原数组

---

**三、哈希表法**

**时间复杂度：O(n)**

详细分析：
1. **插入阶段：** n 次哈希表插入，平均 O(1)
2. **查找阶段：** n+1 次哈希表查找，平均 O(1)
3. **总时间：** ≈ 2n

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 哈希表存储 n 个元素
   - 每个元素有额外开销
   - 实际内存大于数组法

---

**四、排序法**

**时间复杂度：O(n log n)**

详细分析：
1. **排序阶段：** 快排/堆排 O(n log n)
2. **遍历阶段：** O(n)
3. **总时间：** O(n log n) 主导

**空间复杂度：O(1) 或 O(log n)**
取决于排序算法的实现

---

**五、原地标记法**

**时间复杂度：O(n)**

详细分析：
1. **标记阶段：** n 次循环，每次 O(1)
2. **查找阶段：** n 次循环，每次 O(1)
3. **总时间：** 2n

**空间复杂度：O(1)**
在原数组上操作，无额外空间

**缺点：** 修改原数组

---

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 数学求和 | O(n) | O(1) | 直观，简单 | 可能溢出 |
| 位运算 | O(n) | O(1) | 无溢出，效率高 | 需要理解异或 |
| 哈希表 | O(n) | O(n) | 思路直接 | 空间大 |

### **🔍 示例推导**

**示例：nums = [3,0,1]，n = 3，范围 [0,3]**

**数学求和法：**
```
total = 3*4/2 = 6
sum = 3+0+1 = 4
missing = 6-4 = 2
```

**位运算法：**
```
初始 missing = n = 3
i=0: missing = 3 ^ 0 ^ 3 = 0
i=1: missing = 0 ^ 1 ^ 0 = 1
i=2: missing = 1 ^ 2 ^ 1 = 2
结果 = 2
```

**另一种异或写法：**
```
result = 0
先异或下标: 0^1^2^3 = (0^1^2)^3 = 3^3 = 0? 不对，重新算：
0^1=1, 1^2=3, 3^3=0
再异或数组: 0 ^ 3 = 3, 3 ^ 0 = 3, 3 ^ 1 = 2
结果 = 2
```

**原地标记法：**
```
原数组: [3,0,1]
标记:
i=0, val=3, 3<n=3? 3<3? false → 不标记
i=1, val=0, 标记 nums[0] = -nums[0] → [-3,0,1]
i=2, val=1, 标记 nums[1] = -nums[1] → [-3,-0,1] (0还是0)

查找第一个非负数:
i=0: -3 < 0
i=1: -0 == 0 → 返回 1？不对，0是非负数，所以返回0？这里有问题

实际上应该取绝对值再标记，避免0的问题：
for i=0..n-1:
    val = abs(nums[i])
    if val < n:
        nums[val] = -abs(nums[val])  // 确保标记负数

标记后找第一个正数或0的位置
```

---

### **⚠️ 注意事项**

1. **数学求和法的溢出问题**
   - 当 n 很大时，n*(n+1)/2 可能超出 int 范围
   - 可以使用 long long，或者用异或法替代

2. **原地标记法的 0 问题**
   - 标记 0 时，-0 还是 0，无法区分
   - 需要特殊处理，比如将所有数加1再标记，或使用其他标记方式

3. **位运算的理解**
   - 异或的交换律和结合律是关键
   - 推导时要清楚为什么初始值可以设为 n

4. **边界情况**
   - n = 0 时，数组为空，缺失的数就是 0
   - 缺失的数可能是 0 或 n
