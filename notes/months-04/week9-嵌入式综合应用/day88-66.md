个人的思路：
1. 因为这是一个加一题 -> 很自然想到，找数组的最后一位，给他加一 -> 就会有三种情况
   - 个位 无进位，  如123 + 1
   - 有进位 但只是到中部就结束了 如 1399 + 1
   - 进位到最前面 如 99+1 这里就会有一个增加一位数的要求，拓展空间
2. 所以 要做两件事：
   - 判断有无进位 -> 就是加一完之后 ，求余（%10），等于零，说明有进位 ，如果不是，就可以直接复制原数组其他位就好了，然后return
   - 用循环遍历所有位数， 遍历到第一位了，那就是第三种情况，直接多加一个空间，赋值第一位 = 1，其他位 = 0


## #66 加一

**【题目描述】**
给定一个表示大整数的整数数组 digits，其中 digits[i] 是整数的第 i 位数字。这些数字按从左到右，从最高位到最低位排列。这个大整数不包含任何前导 0。将大整数加 1，并返回结果的数字数组。

**【关键词】**
数组 | 进位处理 | 数学模拟

---

### **🧠 思维推导**

**由什么想到什么：**
```
数组表示大整数加1 → 模拟竖式加法从最低位开始
         ↓
  最低位在数组末尾 → 从后向前遍历
         ↓
  遇到9需要进位 → 当前位变0，继续向前进位
         ↓
  如果最高位也进位 → 需要扩展数组（如 999 + 1 = 1000）
```

---

### **核心技巧**

#### 一、从后向前遍历进位法（最优解）

**核心思想：**
从数组末尾开始，模拟加法运算，处理进位情况。

**解题步骤：**
1. 从数组最后一位开始向前遍历
2. 对当前位加1：
   - 如果加1后小于10，则直接返回结果
   - 如果等于10，则当前位变为0，继续向前进位
3. 如果遍历完所有位仍有进位（如 999 + 1），则需要在数组最前面插入1

**代码实现：**
```cpp
vector<int> plusOne(vector<int>& digits) {
    int n = digits.size();
    
    // 从最低位开始处理
    for (int i = n - 1; i >= 0; i--) {
        // 当前位加1
        digits[i]++;
        
        // 如果加1后小于10，没有进位，直接返回
        if (digits[i] < 10) {
            return digits;
        }
        
        // 否则有进位，当前位变0，继续循环处理前一位
        digits[i] = 0;
    }
    
    // 处理特殊情况：所有位都是9，需要扩展数组
    digits.insert(digits.begin(), 1);
    return digits;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)（不考虑返回结果的空间）

---

#### 二、数学进位法

**核心思想：**
显式维护进位变量，模拟加法过程。

**代码实现：**
```cpp
vector<int> plusOne(vector<int>& digits) {
    int carry = 1;  // 初始进位为1（因为要加1）
    int n = digits.size();
    
    for (int i = n - 1; i >= 0 && carry > 0; i--) {
        int sum = digits[i] + carry;
        digits[i] = sum % 10;
        carry = sum / 10;
    }
    
    // 如果仍有进位，需要在前面插入1
    if (carry > 0) {
        digits.insert(digits.begin(), 1);
    }
    
    return digits;
}
```

---

#### 三、递归法

**核心思想：**
用递归处理进位，从最后一位开始。

**代码实现：**
```cpp
vector<int> plusOne(vector<int>& digits) {
    helper(digits, digits.size() - 1);
    return digits;
}

void helper(vector<int>& digits, int index) {
    // 处理完所有位仍有进位
    if (index < 0) {
        digits.insert(digits.begin(), 1);
        return;
    }
    
    digits[index]++;
    if (digits[index] < 10) {
        return;  // 无进位，结束
    }
    
    // 有进位，当前位变0，继续处理前一位
    digits[index] = 0;
    helper(digits, index - 1);
}
```

---

### **📊 复杂度分析（详细版）**

**一、从后向前遍历法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 最坏情况（所有位都是9）：需要遍历所有 n 位
   - 每次循环执行：加1操作、比较、可能的置0操作
   - 总操作次数 ≈ n

2. **最好情况（最后一位小于9）：**
   - 只执行一次循环
   - 时间复杂度 O(1)

3. **平均情况：**
   - 假设数字随机分布，约 90% 的情况只需要处理最后一位
   - 约 9% 的情况需要处理最后两位
   - 期望操作次数 ≈ 1.11，接近 O(1)

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用几个变量（n, i）
   - 所有操作在原数组上进行

2. **特殊情况：**
   - 当所有位都是9时，需要插入新元素
   - 插入操作需要 O(n) 时间，但空间仍是 O(1)（因为是在原数组上操作）

---

**二、数学进位法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 需要处理所有位直到进位为0
   - 最坏情况（999...9）：处理 n 位
   - 平均情况：处理位数较少

2. **与第一种方法的区别：**
   - 显式维护进位变量
   - 逻辑更清晰，但代码稍长

**空间复杂度：O(1)**
与第一种方法相同

---

**三、递归法**

**时间复杂度：O(n)**

详细分析：
1. **递归深度：**
   - 最坏情况递归 n 层
   - 每层 O(1) 操作

**空间复杂度：O(n)**

详细分析：
1. **递归栈：**
   - 最坏情况递归深度为 n
   - 每层栈帧存储参数和返回地址
   - 总空间 ≈ n × 栈帧大小

2. **缺点：** 对于长数组可能栈溢出，不推荐

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 从后向前遍历 | O(n) | O(1) | 空间最优，代码简洁 | 需处理插入情况 |
| 数学进位法 | O(n) | O(1) | 逻辑清晰 | 代码稍长 |
| 递归法 | O(n) | O(n) | 递归思路优雅 | 栈溢出风险 |

### **🔍 示例推导**

**示例1：digits = [1,2,3]**
```
从后向前：
i=2: digits[2]=3 → 3+1=4 <10 → 直接返回 [1,2,4]
```

**示例2：digits = [1,2,9]**
```
i=2: digits[2]=9 → 9+1=10 → digits[2]=0，继续
i=1: digits[1]=2 → 2+1=3 <10 → 返回 [1,3,0]
```

**示例3：digits = [9,9,9]**
```
i=2: 9+1=10 → digits[2]=0
i=1: 9+1=10 → digits[1]=0  
i=0: 9+1=10 → digits[0]=0
循环结束，仍有进位 → 在开头插入1 → [1,0,0,0]
```

### **⚠️ 注意事项**

1. **进位传播**
   - 进位可能连续传播多位（如 199 → 200）
   - 需要正确处理连续进位

2. **数组扩展**
   - 当所有位都是9时（如 999 + 1 = 1000），需要在数组开头插入1
   - 插入操作是 O(n) 的，因为需要移动所有元素

3. **前导0问题**
   - 题目保证输入没有前导0
   - 加1后也不会产生前导0（除非输入是[0]？但[0]加1是[1]，没问题）

4. **大整数表示**
   - 数组可能很长，不能用普通整数类型表示
   - 必须模拟加法过程
