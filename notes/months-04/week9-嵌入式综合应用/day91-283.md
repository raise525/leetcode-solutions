## #283 移动零

**【题目描述】**
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意，必须在不复制数组的情况下原地对数组进行操作。

**【关键词】**
双指针 | 原地操作 | 数组变换

---

### **🧠 思维推导**

**由什么想到什么：**
```
移动零到末尾 → 需要区分零和非零元素
         ↓
  保持非零元素相对顺序 → 不能简单地排序
         ↓
  双指针思路 → 一个指针遍历，一个指针指向非零元素应该放的位置
         ↓
  两种实现方式：交换法 或 覆盖法
```

---

### **核心技巧**

#### 一、双指针交换法（最优解）

**核心思想：**
用两个指针：
- `slow`：指向下一个非零元素应该存放的位置
- `fast`：遍历整个数组

当 `fast` 遇到非零元素时，将其与 `slow` 位置的元素交换，然后 `slow++`。

**解题步骤：**
1. 初始化 slow = 0
2. 遍历 fast 从 0 到 n-1：
   - 如果 nums[fast] != 0：
     - 交换 nums[slow] 和 nums[fast]
     - slow++
3. 遍历结束，所有非零元素都按顺序移到前面，零被交换到后面

**代码实现：**
```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    
    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] != 0) {
            // 交换非零元素到 slow 位置
            swap(nums[slow], nums[fast]);
            slow++;
        }
    }
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 二、双指针覆盖法

**核心思想：**
先遍历一遍，将所有非零元素按顺序放到数组前面，然后后面补零。

**代码实现：**
```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    
    // 第一次遍历：将所有非零元素移到前面
    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] != 0) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    
    // 第二次遍历：将剩余位置补零
    for (int i = slow; i < nums.size(); i++) {
        nums[i] = 0;
    }
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 三、冒泡法（不推荐）

**核心思想：**
类似冒泡排序，将零逐步"冒泡"到末尾。

**代码实现：**
```cpp
void moveZeroes(vector<int>& nums) {
    int n = nums.size();
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (nums[j] == 0 && nums[j + 1] != 0) {
                swap(nums[j], nums[j + 1]);
            }
        }
    }
}
```

**复杂度：**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

---

### **📊 复杂度分析（详细版）**

**一、双指针交换法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 一次遍历：n 次循环
   - 每次遇到非零元素：一次交换操作
   - 交换次数 = 非零元素个数 ≤ n

2. **最好情况（全为非零）：**
   - 每次循环都交换
   - 操作 ≈ n 次交换

3. **最坏情况（全为零）：**
   - 没有交换
   - 只做 n 次判断

4. **平均情况：** 交换次数 ≈ 非零元素个数

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用两个指针变量 slow 和 fast
   - 交换操作使用临时变量，但只占用寄存器或栈空间

2. **原地操作：** 不创建新数组

---

**二、双指针覆盖法**

**时间复杂度：O(n)**

详细分析：
1. **第一次遍历：** n 次循环，每次赋值
2. **第二次遍历：** 补零，循环 n - 非零元素个数 次
3. **总操作次数：** n + (n - k) = 2n - k，其中 k 为非零元素个数

**空间复杂度：O(1)**

与交换法相同，常数空间

---

**三、冒泡法**

**时间复杂度：O(n²)**

详细分析：
1. **外层循环：** n 次
2. **内层循环：** 平均 n/2 次
3. **总比较次数：** ≈ n²/2
4. **交换次数：** 取决于零的分布

**为什么不好：**
- n = 10⁴ 时，比较次数 ≈ 5 × 10⁷
- 严重超时

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 交换法 | O(n) | O(1) | 一次遍历，代码简洁 | 需理解双指针思想 |
| 覆盖法 | O(n) | O(1) | 思路直观 | 需要两次遍历 |
| 冒泡法 | O(n²) | O(1) | 思路简单 | 效率极低 |

### **🔍 双指针交换法详解**

**算法演示：**
```
nums = [0, 1, 0, 3, 12]

初始：slow = 0

fast=0: nums[0]=0 → 不交换
fast=1: nums[1]=1 → swap(nums[0], nums[1]) → [1, 0, 0, 3, 12], slow=1
fast=2: nums[2]=0 → 不交换
fast=3: nums[3]=3 → swap(nums[1], nums[3]) → [1, 3, 0, 0, 12], slow=2
fast=4: nums[4]=12 → swap(nums[2], nums[4]) → [1, 3, 12, 0, 0], slow=3

结果：[1, 3, 12, 0, 0]
```

**为什么能保持相对顺序？**
- slow 指针始终指向下一个非零元素应该放的位置
- fast 指针按顺序遍历，遇到非零元素就放到 slow 位置
- 这样非零元素按原顺序被移到前面

**交换的优化：**
当 fast == slow 时，交换自身没有意义，可以加一个判断：
```cpp
if (fast != slow) {
    swap(nums[slow], nums[fast]);
}
slow++;
```

### **🔍 两种双指针法的比较**

**交换法特点：**
- 一次遍历完成
- 零会被交换到中间位置，但最终都在末尾
- 需要理解交换的意义

**覆盖法特点：**
- 两次遍历，逻辑更清晰
- 先覆盖非零元素，再补零
- 可能会覆盖一些值（但已经用过了）

**性能对比：**
```
数组 [0,1,0,3,12]

交换法操作：
- 判断 5 次
- 交换 3 次

覆盖法操作：
- 第一次遍历：5 次判断，3 次赋值
- 第二次遍历：2 次赋值
- 总：5 次判断，5 次赋值
```

两者时间复杂度相同，常数因子略有差异

---

### **⚠️ 注意事项**

1. **原地操作**
   - 不能创建新数组
   - 必须在原数组上修改

2. **保持相对顺序**
   - 非零元素的顺序不能变
   - 这是题目关键要求

3. **边界情况**
   - 空数组：直接返回
   - 全零数组：不做任何操作
   - 全非零数组：slow 和 fast 同步移动，交换自身（可优化）

4. **交换 vs 覆盖**
   - 交换法不会丢失数据
   - 覆盖法需要确保非零元素已经被处理
