## #169 多数元素

**【题目描述】**
给定一个大小为 n 的数组 nums，返回其中的多数元素。多数元素是指在数组中出现次数大于 ⌊ n/2 ⌋ 的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**【关键词】**
摩尔投票算法 | 哈希表 | 排序 | 分治

---

### **🧠 思维推导**

**由什么想到什么：**
```
出现次数 > n/2 → 这个数一定比其他所有数出现次数都多
         ↓
  抵消思想 → 不同的数两两抵消，最后剩下的就是多数元素
         ↓
  摩尔投票算法 → 维护一个候选者和计数，遍历一次即可
         ↓
  也可用哈希表统计次数，或排序后取中间元素
```

---

### **核心技巧**

#### 一、摩尔投票算法（Boyer-Moore Voting Algorithm）- 最优解

**核心思想：**
不同的数两两抵消，最后剩下的候选者就是多数元素。

**算法原理：**
1. 维护一个候选者 candidate 和一个计数 count
2. 遍历数组：
   - 如果 count == 0，将当前元素设为 candidate
   - 如果当前元素 == candidate，count++
   - 否则，count--（相当于当前元素和 candidate 抵消一对）

**为什么有效？**
多数元素的个数 > n/2，所以抵消后它一定还会剩余。

**代码实现：**
```cpp
int majorityElement(vector<int>& nums) {
    int candidate = nums[0];
    int count = 1;
    
    for (int i = 1; i < nums.size(); i++) {
        if (count == 0) {
            candidate = nums[i];
            count = 1;
        } else if (nums[i] == candidate) {
            count++;
        } else {
            count--;
        }
    }
    
    return candidate;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 二、哈希表计数法

**核心思想：**
用哈希表统计每个元素出现的次数，找到次数 > n/2 的元素。

**代码实现：**
```cpp
int majorityElement(vector<int>& nums) {
    unordered_map<int, int> countMap;
    int n = nums.size();
    
    for (int num : nums) {
        countMap[num]++;
        if (countMap[num] > n / 2) {
            return num;
        }
    }
    
    return -1; // 不会执行到这里
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 三、排序法

**核心思想：**
对数组排序，由于多数元素出现次数 > n/2，排序后它一定位于中间位置。

**代码实现：**
```cpp
int majorityElement(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    return nums[nums.size() / 2];
}
```

**复杂度：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(1)（原地排序）

---

#### 四、分治法

**核心思想：**
将数组分成两半，分别找出左半边的多数元素和右半边的多数元素，然后合并。

**代码实现：**
```cpp
int majorityElement(vector<int>& nums) {
    return majorityElementRec(nums, 0, nums.size() - 1);
}

int majorityElementRec(vector<int>& nums, int left, int right) {
    if (left == right) {
        return nums[left];
    }
    
    int mid = left + (right - left) / 2;
    int leftMajor = majorityElementRec(nums, left, mid);
    int rightMajor = majorityElementRec(nums, mid + 1, right);
    
    // 如果左右两边的多数元素相同，直接返回
    if (leftMajor == rightMajor) {
        return leftMajor;
    }
    
    // 否则统计两个候选者在当前区间的出现次数
    int leftCount = countInRange(nums, leftMajor, left, right);
    int rightCount = countInRange(nums, rightMajor, left, right);
    
    return leftCount > rightCount ? leftMajor : rightMajor;
}

int countInRange(vector<int>& nums, int target, int left, int right) {
    int count = 0;
    for (int i = left; i <= right; i++) {
        if (nums[i] == target) {
            count++;
        }
    }
    return count;
}
```

**复杂度：**
- 时间复杂度：O(n log n)（每层需要统计次数）
- 空间复杂度：O(log n)（递归栈）

---

#### 五、随机化法

**核心思想：**
随机选择一个元素，验证它是否是多数元素。由于多数元素占比超过一半，随机选中的概率 > 1/2，期望时间复杂度 O(n)。

**代码实现：**
```cpp
int majorityElement(vector<int>& nums) {
    int n = nums.size();
    
    while (true) {
        int candidate = nums[rand() % n];
        int count = 0;
        for (int num : nums) {
            if (num == candidate) {
                count++;
            }
        }
        if (count > n / 2) {
            return candidate;
        }
    }
}
```

**复杂度：**
- 期望时间复杂度：O(n)
- 最坏时间复杂度：O(∞)（理论上可能永远选不中，但概率极低）
- 空间复杂度：O(1)

---

### **📊 复杂度分析（详细版）**

**一、摩尔投票算法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 一次遍历：n-1 次循环
   - 每次循环：比较和计数操作
   - 总操作 ≈ n

2. **常数因子：**
   - 只有简单的比较和加减
   - 非常高效

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用两个变量 candidate 和 count
   - 固定大小，与 n 无关

2. **优点：** 真正的常数空间

---

**二、哈希表法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历数组：n 次循环
   - 每次循环：哈希表插入/更新 O(1)
   - 可能提前退出（当找到多数元素时）

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 最坏情况（所有元素不同）：存储 n 个键值对
   - 实际存储的元素数取决于不同值的数量

---

**三、排序法**

**时间复杂度：O(n log n)**

详细分析：
1. **排序阶段：** O(n log n)
2. **取中间元素：** O(1)
3. **总时间：** 排序主导

**空间复杂度：O(1) 或 O(log n)**
取决于排序算法的实现

---

**四、分治法**

**时间复杂度：O(n log n)**

详细分析：
1. **递归分解：** log n 层
2. **每层统计次数：** O(n)（需要统计左右候选者在当前区间的出现次数）
3. **总时间：** n × O(log n) = O(n log n)

**空间复杂度：O(log n)**
递归栈深度

**五、随机化法**

**期望时间复杂度：O(n)**

详细分析：
1. **选中概率：** p > 1/2
2. **期望尝试次数：** < 2
3. **每次尝试：** O(n) 遍历验证
4. **期望时间：** < 2n = O(n)

### **🔍 摩尔投票算法详解**

**算法演示：**
```
nums = [2, 2, 1, 1, 1, 2, 2]

初始化：candidate = 2, count = 1

i=1: nums[1]=2 == candidate → count=2
i=2: nums[2]=1 != candidate → count=1
i=3: nums[3]=1 != candidate → count=0
i=4: count==0 → candidate=1, count=1
i=5: nums[5]=2 != candidate → count=0
i=6: count==0 → candidate=2, count=1

结果：candidate = 2（多数元素）
```

**为什么最后 candidate 一定是多数元素？**
- 每次 count 归零时，表示前面已经处理过的部分中，多数元素和其他元素抵消完了
- 多数元素的总数 > n/2，所以抵消后它一定还会剩余
- 这个算法是确定性的，不需要随机化

**数学证明：**
设多数元素为 m，出现次数为 M > n/2
- 每次 count 归零时，表示前面部分中 m 和其他元素数量相等
- 但 m 的总数大于一半，所以最后一定会剩下 m

   - 所有元素相同的情况也能正确处理
