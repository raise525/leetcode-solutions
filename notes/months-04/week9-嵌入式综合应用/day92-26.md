个人的思路：
1. 因为是在原地修改 -> 双指针 ，是在数组上 -> 用两个下标当指针i=0， j=1 ； 
 - 相等则 j++,
 - 不相等 则 nums[++i] = nums[j] ,然后j++
 - 因为两都要j++,可以直接合并，只用判断 不相等的时候就好了，注意结束的条件是： j > size(遍历完成)

## #26 删除有序数组中的重复项

**【题目描述】**
给你一个非严格递增排列的数组 nums，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应该保持一致。nums 的前 k 个元素应包含排序后的唯一数字，下标 k-1 之后的剩余元素可以忽略。

**【关键词】**
双指针 | 原地操作 | 有序数组 | 去重

---

### **🧠 思维推导**

**由什么想到什么：**
```
有序数组 + 删除重复 → 重复元素必然相邻
         ↓
  需要保留每个元素的一个副本 → 双指针
         ↓
  slow 指向下一个唯一元素应该放的位置
  fast 遍历数组，遇到新元素就放到 slow 位置
```

---

### **核心技巧**

#### 一、双指针法（最优解）

**核心思想：**
- 由于数组是有序的，重复元素必然连续出现
- 用两个指针：
  - `slow`：指向下一个唯一元素应该存放的位置
  - `fast`：遍历整个数组
- 当 `fast` 遇到与上一个唯一元素不同的值时，将其放到 `slow` 位置，并移动 `slow`

**解题步骤：**
1. 如果数组长度为 0，直接返回 0
2. 初始化 slow = 1（因为第一个元素一定保留）
3. 遍历 fast 从 1 到 n-1：
   - 如果 nums[fast] != nums[slow-1]（即不等于上一个唯一元素）：
     - 将 nums[fast] 赋值给 nums[slow]
     - slow++
4. 返回 slow（即唯一元素的个数）

**代码实现：**
```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    
    int slow = 1;  // 下一个唯一元素应该放的位置
    
    for (int fast = 1; fast < nums.size(); fast++) {
        // 如果当前元素不等于上一个唯一元素
        if (nums[fast] != nums[slow - 1]) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    
    return slow;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

#### 二、双指针法（另一种写法）

**核心思想：**
slow 指向当前已处理的不重复序列的末尾，fast 向前探索新元素。

**代码实现：**
```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    
    int slow = 0;
    
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    
    return slow + 1;
}
```

---

#### 三、使用 STL 的 unique 函数

**核心思想：**
C++ 标准库提供了 `std::unique` 函数，专门用于去除有序容器中的连续重复元素。

**代码实现：**
```cpp
int removeDuplicates(vector<int>& nums) {
    auto it = unique(nums.begin(), nums.end());
    return distance(nums.begin(), it);
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

---

### **📊 复杂度分析（详细版）**

**一、双指针法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 一次遍历：n 次循环
   - 每次循环：一次比较，可能的一次赋值
   - 赋值次数 = 唯一元素个数 - 1

2. **最好情况（全为唯一元素）：**
   - 每次循环都赋值
   - 操作 ≈ 2n

3. **最坏情况（全相同）：**
   - 只有比较，没有赋值
   - 操作 ≈ n

**空间复杂度：O(1)**

详细分析：
1. **内存占用：**
   - 只使用两个指针变量 slow 和 fast
   - 原地操作，不创建新数组

---

**二、STL unique 函数**

**时间复杂度：O(n)**

详细分析：
1. `unique` 内部实现也是双指针遍历
2. 与手写版本时间复杂度相同

**空间复杂度：O(1)**

---

### **🔍 算法演示**

**示例：nums = [0,0,1,1,1,2,2,3,3,4]**

```
初始：slow = 1

fast=1: nums[1]=0 == nums[0] → 不操作
fast=2: nums[2]=1 != nums[0] → nums[1]=1, slow=2
fast=3: nums[3]=1 == nums[1] → 不操作
fast=4: nums[4]=1 == nums[1] → 不操作
fast=5: nums[5]=2 != nums[1] → nums[2]=2, slow=3
fast=6: nums[6]=2 == nums[2] → 不操作
fast=7: nums[7]=3 != nums[2] → nums[3]=3, slow=4
fast=8: nums[8]=3 == nums[3] → 不操作
fast=9: nums[9]=4 != nums[3] → nums[4]=4, slow=5

结果：前 5 个元素为 [0,1,2,3,4]，返回 5
```

---

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双指针 | O(n) | O(1) | 空间最优，代码可控 | 需要理解指针思想 |
| STL unique | O(n) | O(1) | 一行代码，可靠 | 依赖标准库 |

### **⚠️ 注意事项**

1. **原地操作**
   - 不能创建新数组
   - 必须直接在原数组上修改

2. **返回值含义**
   - 返回的是唯一元素的个数 k
   - 数组前 k 个元素是去重后的结果
   - 后面元素可以忽略

3. **有序数组的前提**
   - 题目保证数组是非严格递增的
   - 这个性质保证了重复元素相邻

4. **边界情况**
   - 空数组：返回 0
   - 单元素数组：返回 1
   - 全相同数组：返回 1
