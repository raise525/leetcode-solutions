## #338 比特位计数

**【题目描述】**
给你一个整数 n，对于 0 <= i <= n 中的每个 i，计算其二进制表示中 1 的个数，返回一个长度为 n + 1 的数组 ans 作为答案。

**【关键词】**
位运算 | 动态规划 | 二进制 | 计数

---

### **🧠 思维推导**

**由什么想到什么：**
```
计算 0 到 n 每个数的二进制中 1 的个数 → 暴力法每个数单独计算 O(n log n)
         ↓
  相邻数之间二进制有关系 → 动态规划
         ↓
  关键观察：x 与 x/2 的关系 → x 的 1 个数 = x/2 的 1 个数 + (x 的最低位是否为 1)
         ↓
  或者用 x & (x-1) 的性质 → x 的 1 个数 = (x & (x-1)) 的 1 个数 + 1
```

---

### **核心技巧**

#### 一、动态规划 + 最低位法（最优解）

**核心思想：**
- 对于任意整数 x，将其右移一位（即除以 2），得到 floor(x/2)
- x 的二进制表示中 1 的个数 = floor(x/2) 的 1 的个数 + (x 的最低位是否为 1)

**状态转移方程：**
```
dp[x] = dp[x >> 1] + (x & 1)
```
其中 `x >> 1` 是 x 除以 2 向下取整，`x & 1` 是 x 的最低位。

**解题步骤：**
1. 创建长度为 n+1 的数组 dp
2. dp[0] = 0（0 的二进制没有 1）
3. 遍历 i 从 1 到 n：
   - dp[i] = dp[i >> 1] + (i & 1)
4. 返回 dp

**代码实现：**
```cpp
vector<int> countBits(int n) {
    vector<int> dp(n + 1, 0);
    
    for (int i = 1; i <= n; i++) {
        // i >> 1 相当于 i / 2
        // i & 1 是 i 的最低位
        dp[i] = dp[i >> 1] + (i & 1);
    }
    
    return dp;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 二、动态规划 + 最高有效位法

**核心思想：**
- 对于区间 [2^k, 2^(k+1)-1] 内的数，它们的二进制表示是 1 后面跟着 [0, 2^k-1] 的二进制
- 因此 `dp[i] = dp[i - 2^k] + 1`，其中 2^k 是小于等于 i 的最大 2 的幂

**解题步骤：**
1. 创建长度为 n+1 的数组 dp
2. dp[0] = 0
3. 维护一个变量 highBit，表示当前段的最高有效位
4. 遍历 i 从 1 到 n：
   - 如果 i 是 2 的幂，更新 highBit = i
   - dp[i] = dp[i - highBit] + 1

**代码实现：**
```cpp
vector<int> countBits(int n) {
    vector<int> dp(n + 1, 0);
    int highBit = 0;
    
    for (int i = 1; i <= n; i++) {
        // 判断 i 是否是 2 的幂
        if ((i & (i - 1)) == 0) {
            highBit = i;
        }
        dp[i] = dp[i - highBit] + 1;
    }
    
    return dp;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 三、动态规划 + 最低设置位法

**核心思想：**
- `x & (x-1)` 会将 x 的最低位的 1 变为 0
- 因此 `dp[x] = dp[x & (x-1)] + 1`

**代码实现：**
```cpp
vector<int> countBits(int n) {
    vector<int> dp(n + 1, 0);
    
    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i & (i - 1)] + 1;
    }
    
    return dp;
}
```

**复杂度：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

---

#### 四、暴力法（不推荐）

**核心思想：**
对每个数单独计算二进制中 1 的个数。

**代码实现：**
```cpp
int countOnes(int x) {
    int count = 0;
    while (x > 0) {
        count += x & 1;
        x >>= 1;
    }
    return count;
}

vector<int> countBits(int n) {
    vector<int> ans(n + 1);
    for (int i = 0; i <= n; i++) {
        ans[i] = countOnes(i);
    }
    return ans;
}
```

**复杂度：**
- 时间复杂度：O(n log n)（每个数需要 O(log i) 时间）
- 空间复杂度：O(n)

---

### **📊 复杂度分析（详细版）**

**一、动态规划 + 最低位法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历 i 从 1 到 n：n 次循环
   - 每次循环执行：
     * 一次右移操作（`i >> 1`）
     * 一次按位与操作（`i & 1`）
     * 一次加法
     * 一次数组访问

2. **总操作次数：** 约 4n

**空间复杂度：O(n)**

详细分析：
1. **内存占用：**
   - 返回的数组需要存储 n+1 个 int
   - 空间：4(n+1) 字节（32 位系统）或 8(n+1) 字节（64 位系统）

---

**二、动态规划 + 最低设置位法**

**时间复杂度：O(n)**

详细分析：
1. **操作分解：**
   - 遍历 i 从 1 到 n：n 次循环
   - 每次循环执行：
     * 一次 `i & (i-1)` 操作
     * 一次数组访问
     * 一次加法

**空间复杂度：O(n)**
与最低位法相同

---

**三、暴力法**

**时间复杂度：O(n log n)**

详细分析：
1. **操作分解：**
   - 对于每个 i，需要遍历其二进制位数
   - 总操作次数 ≈ 0 + 1 + 2 + ... + log₂n ≈ n log₂n

2. **数值示例：**
   - n = 10⁶ 时，log₂n ≈ 20
   - 总操作 ≈ 2 × 10⁷，仍然可行但不如 DP 高效

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 最低位 DP | O(n) | O(n) | 最直观的 DP | 需要理解转移方程 |
| 最高位 DP | O(n) | O(n) | 数学思路清晰 | 需要判断 2 的幂 |
| 最低设置位 DP | O(n) | O(n) | 代码最简洁 | 需要理解 `x & (x-1)` |
| 暴力法 | O(n log n) | O(n) | 思路简单 | 效率较低 |

---

### **🔍 三种 DP 方法详解**

**一、最低位法原理：**
```
二进制表示中，x 和 x/2 的关系：
x = (x/2) * 2 + (x % 2)
因此 popcount(x) = popcount(x/2) + (x % 2)

示例：
i=5 (101) → i>>1=2 (10), i&1=1 → dp[5]=dp[2]+1=1+1=2
i=6 (110) → i>>1=3 (11), i&1=0 → dp[6]=dp[3]+0=2+0=2
```

**二、最高位法原理：**
```
区间划分：
[0] → 0
[1,1] → 1
[2,3] → 1 + [0,1] 的 popcount
[4,7] → 1 + [0,3] 的 popcount
[8,15] → 1 + [0,7] 的 popcount

示例：
i=5: highBit=4, dp[5]=dp[5-4]+1=dp[1]+1=1+1=2
i=6: highBit=4, dp[6]=dp[2]+1=1+1=2
```

**三、最低设置位法原理：**
```
x & (x-1) 会清除 x 的最低位的 1
因此 popcount(x) = popcount(x & (x-1)) + 1

示例：
i=5 (101): 5&4=4 (100), dp[5]=dp[4]+1=1+1=2
i=6 (110): 6&5=4 (100), dp[6]=dp[4]+1=1+1=2
i=7 (111): 7&6=6 (110), dp[7]=dp[6]+1=2+1=3
```

---

### **⚠️ 注意事项**

1. **n 的范围**
   - 题目没有明确给出范围，但 DP 方法可以轻松处理 n ≤ 10⁵

2. **dp[0] 的处理**
   - 0 的二进制表示中没有 1，dp[0] = 0

3. **递推的基础**
   - 所有方法都需要 dp[0] 作为基础

4. **位运算优先级**
   - `>>` 优先级低于 `+`，但 `+` 优先级低于 `<<`？
   - 实际 `+` 优先级高于 `>>`，所以 `dp[i>>1] + (i&1)` 等价于 `(dp[i>>1]) + (i&1)`
