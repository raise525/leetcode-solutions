## #160 相交链表

**【题目描述】**
给你两个单链表的头节点 headA 和 headB，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 null。

**【关键词】**
链表 | 双指针 | 哈希表 | 相交

---

### **🧠 思维推导**

**由什么想到什么：**
```
找两个链表的相交节点 → 如果相交，从某个节点开始后续节点全部相同
         ↓
  问题：两个链表长度可能不同 → 需要对齐尾部
         ↓
  方法一：计算长度差，让长链表先走差值步，再同步走
         ↓
  方法二：双指针走完自己的链表后换到另一个链表 → 消除长度差
         ↓
  方法三：用哈希表记录一个链表的所有节点，遍历另一个链表查找
```

---

### **核心技巧**

#### 一、双指针法（最优解）

**核心思想：**
- 创建两个指针 pA 和 pB，分别指向 headA 和 headB
- 两个指针同时向前移动
- 当 pA 到达末尾时，将其指向 headB；当 pB 到达末尾时，将其指向 headA
- 这样两个指针走过的总长度相同，如果有相交节点，一定会在相交点相遇

**数学原理：**
设链表 A 的非公共部分长度为 a，链表 B 的非公共部分长度为 b，公共部分长度为 c。
- pA 走过的路径：a + c + b
- pB 走过的路径：b + c + a
- 两者长度相等，会在公共部分的第一个节点相遇

**解题步骤：**
1. 如果 headA 或 headB 为空，返回 null
2. 初始化 pA = headA，pB = headB
3. 当 pA != pB 时循环：
   - pA 向前移动一步，如果到达末尾则指向 headB
   - pB 向前移动一步，如果到达末尾则指向 headA
4. 返回 pA（或 pB）

**代码实现：**
```cpp
ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
    if (headA == nullptr || headB == nullptr) {
        return nullptr;
    }
    
    ListNode *pA = headA;
    ListNode *pB = headB;
    
    while (pA != pB) {
        pA = (pA == nullptr) ? headB : pA->next;
        pB = (pB == nullptr) ? headA : pB->next;
    }
    
    return pA;
}
```

**复杂度：**
- 时间复杂度：O(m + n)，m 和 n 分别是两个链表的长度
- 空间复杂度：O(1)

---

#### 二、长度差法

**核心思想：**
- 先分别计算两个链表的长度
- 让较长的链表先走长度差步，使两个链表尾部对齐
- 然后同时移动两个指针，第一个相同节点就是相交节点

**代码实现：**
```cpp
ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
    if (headA == nullptr || headB == nullptr) {
        return nullptr;
    }
    
    // 计算链表长度
    int lenA = 0, lenB = 0;
    ListNode *pA = headA, *pB = headB;
    
    while (pA != nullptr) {
        lenA++;
        pA = pA->next;
    }
    while (pB != nullptr) {
        lenB++;
        pB = pB->next;
    }
    
    // 让长链表先走差值步
    pA = headA;
    pB = headB;
    int diff = abs(lenA - lenB);
    
    if (lenA > lenB) {
        while (diff--) {
            pA = pA->next;
        }
    } else {
        while (diff--) {
            pB = pB->next;
        }
    }
    
    // 同步移动，找相交点
    while (pA != pB) {
        pA = pA->next;
        pB = pB->next;
    }
    
    return pA;
}
```

**复杂度：**
- 时间复杂度：O(m + n)
- 空间复杂度：O(1)

---

#### 三、哈希表法

**核心思想：**
- 遍历链表 A，将所有节点存入哈希集合
- 遍历链表 B，检查每个节点是否在哈希集合中
- 第一个在集合中的节点就是相交节点

**代码实现：**
```cpp
ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
    unordered_set<ListNode*> visited;
    
    // 记录链表 A 的所有节点
    ListNode *p = headA;
    while (p != nullptr) {
        visited.insert(p);
        p = p->next;
    }
    
    // 遍历链表 B，找第一个在集合中的节点
    p = headB;
    while (p != nullptr) {
        if (visited.count(p)) {
            return p;
        }
        p = p->next;
    }
    
    return nullptr;
}
```

**复杂度：**
- 时间复杂度：O(m + n)
- 空间复杂度：O(m) 或 O(n)

---

#### 四、标记法（破坏链表，不推荐）

**核心思想：**
- 遍历链表 A，将每个节点的 next 指针指向自己（或特殊标记）
- 遍历链表 B，第一个遇到被标记的节点就是相交节点
- **缺点：** 会破坏原链表结构

---

### **📊 复杂度分析（详细版）**

**一、双指针法**

**时间复杂度：O(m + n)**

详细分析：
1. **操作分解：**
   - 两个指针最多各走 m + n 步
   - 最坏情况：没有相交节点，每个指针都要走完两个链表
   - 总移动次数 ≈ m + n

2. **最好情况：**
   - 头节点就相交：一次比较就找到

**空间复杂度：O(1)**
只使用两个指针变量

---

**二、长度差法**

**时间复杂度：O(m + n)**

详细分析：
1. **第一次遍历：** 计算长度，O(m + n)
2. **对齐操作：** O(|m - n|)
3. **第二次遍历：** 找相交点，最坏 O(min(m, n))
4. **总时间：** O(m + n)

**空间复杂度：O(1)**

---

**三、哈希表法**

**时间复杂度：O(m + n)**

详细分析：
1. **存储链表 A：** O(m)
2. **遍历链表 B：** O(n)
3. **每次查找：** O(1)

**空间复杂度：O(m)** 或 **O(n)**

---

### **📈 各方法对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双指针 | O(m+n) | O(1) | 空间最优，代码简洁 | 需要理解数学原理 |
| 长度差 | O(m+n) | O(1) | 思路直观 | 需要两次遍历 |
| 哈希表 | O(m+n) | O(m) | 最直观 | 需要额外空间 |

---

### **🔍 双指针法详细演示**

**示例：**
```
链表 A: 1 → 2 → 3 ↘
                 4 → 5 → 6
链表 B: 7 → 8 ↗

a = 3 (1,2,3), b = 2 (7,8), c = 3 (4,5,6)
```

**指针移动过程：**
```
pA: 1 → 2 → 3 → 4 → 5 → 6 → null → 7 → 8 → 4 → 5 → 6 → null
pB: 7 → 8 → 4 → 5 → 6 → null → 1 → 2 → 3 → 4 → 5 → 6 → null
                        ↑
                    在此相遇
```

**无相交节点的情况：**
```
pA 和 pB 会同时到达 null，返回 null
```

---

### **⚠️ 注意事项**

1. **相交的定义**
   - 相交是指节点地址相同，不只是值相同
   - 所以不能用节点值判断，必须用指针/引用比较

2. **链表结构**
   - 相交后，所有后续节点都是共享的
   - 不会出现"X"形相交（Y 形是唯一可能）

3. **边界情况**
   - 其中一个链表为空：返回 null
   - 头节点就是相交节点：双指针法也能正确处理

4. **双指针法的终止条件**
   - 当 pA == pB 时停止
   - 如果没有相交，最终都会变成 null，也会相等
