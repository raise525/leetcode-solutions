## 3. 面试题：`static` 关键字的作用

`static` 在 C 语言中有以下三种用途：

### 1. 修饰局部变量
- 生命周期延长至程序结束
- 作用域仍限于函数内部
- 只初始化一次，再次调用时保留上次的值

```c
void func() {
    static int count = 0;  // 只初始化一次
    count++;
}
```

### 2. 修饰全局变量
- 作用域限制在当前文件
- 其他文件无法通过 `extern` 访问

```c
static int num = 10;  // 仅当前文件可见
```

### 3. 修饰函数
- 作用域限制在当前文件
- 其他文件无法调用

```c
static void helper() {
    // 仅当前文件内部调用
}
```

---

### 总结

| 用途 | 作用域 | 生命周期 | 特点 |
|------|--------|----------|------|
| 局部变量 + static | 函数内部 | 程序运行期间 | 保留值，仅初始化一次 |
| 全局变量 + static | 当前文件 | 程序运行期间 | 隐藏符号，避免命名冲突 |
| 函数 + static | 当前文件 | 程序运行期间 | 文件私有，不可外部调用 |
