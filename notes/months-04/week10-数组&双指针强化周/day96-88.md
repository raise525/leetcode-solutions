## 1. **算法思维层面的收获**

### 逆向思维
- 这道题的精髓是**从后往前填充**，避免了移动元素的开销
- 遇到数组合并、插入类问题，考虑是否可以从末尾开始操作

### 双指针技巧
- 同时追踪两个数组的当前位置
- 经典模式：`while(i >= 0 && j >= 0)` 处理公共部分，然后处理剩余部分

## 2. **代码细节上的易错点**

### 运算符混淆
```c
// 错误
while(i & j != 0)  // 按位与，不是你要的

// 正确
while(i >= 0 && j >= 0)  // 逻辑与
```
**教训**：C 语言中 `&` 和 `&&` 完全不同，容易手误

### 边界条件处理
```c
// 容易漏掉 j == 0 的情况
if(j > 0)  // ❌

// 应该包含等于的情况
if(j >= 0)  // ✓
```
**教训**：边界条件要仔细考虑 `0` 和 `-1` 的区别

### 循环语法规范
```c
// 不规范但能编译
for(j; j >= 0; j--)

// 更清晰的写法
for(; j >= 0; j--)  // 或直接用 while
```
**教训**：养成写规范代码的习惯

对于这类题，记住测试：

```c
void merge(int* nums1, int m, int* nums2, int n) {
    int i = m - 1, j = n - 1, p = m + n - 1;
    
    while (i >= 0 && j >= 0) {
        nums1[p--] = (nums1[i] > nums2[j]) ? nums1[i--] : nums2[j--];

        nums1[p--] = nums2[j--];
    }
}
```

1. 面试题：堆和栈的区别？
   - 栈是先入后出, 栈是系统给的空间？
   - 堆是什么东西？堆是自己申请开辟的空间，要自己处理

`一句话`：**堆**由程序员手动分配释放，速度慢且易产生碎片；**栈**由编译器自动管理，速度快但空间有限。

## 堆和栈的区别（简要版）

### 用生活例子理解

**栈**：就像**叠盘子**
- 后放的盘子先拿（后进先出）
- 放盘子、拿盘子都很简单快速
- 盘子数量固定，太多会倒（栈溢出）

**堆**：就像**仓库里的货架**
- 想放哪就放哪，想拿哪个就拿哪个
- 但需要自己记住放哪了，用完了要自己清理
- 空间大，但找地方放东西比较慢

### 核心区别

| 对比项 | 栈 | 堆 |
|-------|---|----|
| **谁管** | 自动（编译器管） | 手动（你管） |
| **怎么用** | 直接定义变量 | 用 malloc/free |
| **速度** | 快 | 慢 |
| **大小** | 小（通常1-8MB） | 大（看内存） |
| **释放** | 自动释放 | 必须手动 free |

### 代码示例

```c
void test() {
    // 栈：自动分配，自动释放
    int a = 10;        // 在栈上
    char str[100];     // 在栈上
    
    // 堆：手动分配，必须手动释放
    int *p = malloc(sizeof(int));  // 在堆上
    *p = 20;
    free(p);  // 不释放会内存泄漏！
}
```

### 嵌入式要注意

```c
// 栈别用太大
void bad() {
    char buf[10000];  // 可能栈溢出！
}

// 大数组放全局或静态
static char buf[10000];  // 不在栈上，安全
```

### 记忆口诀
- **栈**：自动、快速、小、省心
- **堆**：手动、慢、大、要操心
